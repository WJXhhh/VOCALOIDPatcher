## 位23：DRS解析响应与DSE运行时响应有别

先前独立公式正确重现的是DRS分析侧`0x77e40`的解析共振响应。
实际DSE运行时`0x12da40`使用二维表，单共振线性幅度入口为`0x12d7d0`：

```text
x = min(abs(frequency - center) / 5, 1599)
y = min((bandwidth - 20) / 10, 147)
i = trunc(x);  tx = x - i
j = trunc(y);  ty = y - j

low  = T[j,i]   + tx * (T[j,i+1]   - T[j,i])
high = T[j+1,i] + tx * (T[j+1,i+1] - T[j+1,i])
response = (low + ty*(high-low)) * linear_amplitude
```

表T起于`0x5ef130`，每行1601个double。频率距离每5Hz一格，带宽每10Hz一格，
首带宽为20Hz。先由共振setter将带宽限制在20–1500Hz，求值器再按上述坐标限制取样；
所以1490Hz以上的带宽坐标固定为147，7995Hz以上的距离坐标固定为1599。
不能省略带宽方向的插值，也不能用纯解析响应替换后仍声称数值相同。

DSE共振对象的中心、对数幅度、线性幅度、带宽分别在`+0x140/+0x148/+0x150/+0x158`，
setter为`0x137ad0`；它没有DRS对象内的完整解析滤波器系数。
两列表仍在线性幅度域求和，float化后转回20log10幅度，再加指数曲线和位23。
基本物理模型与旧公式一致，但其数值实现多了查表和双线性插值。

`frm2_dse_model.py`分别实现原生调用与独立双线性插值。
独立实现只从本机DLL读取所需四个表格值，没有复制整张专有表到仓库。
表格值作为运行时常量输入；本轮不宣称已恢复厂商离线生成该常量表的全部舍入流程。

自有中心、幅度、带宽和距离组合覆盖非整数位置、两端夹紧、零线性幅度：
**936次单共振求值、648次完整模型及648次幅度分支切换均零误差**。
另对669个商业帧的43,428个有效谐波点比较原生完整模型与独立实现，
最大差7.6294e-6，全部通过1e-4。

## 完整位23重建及两端规则

用DSE查表模型替换DRS解析模型之后，还必须遵循幅度ENV的首末端规则：

1. 0Hz输入幅度为第一谐波幅度减3dB。
2. 各正频率谐波按最近30Hz网格位置提供残差节点，节点值为源幅度减DSE模型幅度。
3. 幅度ENV的22050Hz端点为**最后一个严格位于范围内的谐波幅度减3dB**。
   若数组还有大于或等于22050Hz的谐波，源幅度取这个端点，模型仍在该谐波频率求值，
   其残差节点落到网格末项。直接使用那个越界谐波自己的幅度会产生错误。
4. 节点间按索引线性填充，再将各网格值限制在[-100,10]；填充后的值舍入为float。
5. 最后节点之后未填充的网格保持0。普通网格共736项，包含22050Hz端点。

DRS临时幅度ENV构造的汇编也确认首末内点各减3dB；`0x003af0`将范围外横坐标
写入端点，构造完成时再用最后一个内点更新高端值。这解释了超上限谐波的处理。

这是对**整份保存位23包络**的重建，不是只比较谐波节点，也不是仅复用保存的位23
做消费公式检查。数值精度达到1e-4验收阈值，不等于每个float逐位相同。
目前商业位23是669帧分层验证，不能与位22的856,983帧全量检查混称同一覆盖范围。
