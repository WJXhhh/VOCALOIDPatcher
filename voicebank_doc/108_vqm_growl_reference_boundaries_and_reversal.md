## 一、参考频率边界：完成

### 规则及适用条件

入口 `0x158E40`，计算范围 `0x158F90..0x158FF8`，Hz→cent帮助函数 `0x1589D0`，cent→Hz及谐波重排 `0x159027..0x159092`。本轮输入为有效的1/2/3/15/16项数组，工作帧bit0/bit1均置位；缺失幅度常量为 **10000**，固定位置 `0x5BFDCC` 在本机DLL中已核对。

| 条件 | 动态确认的行为 |
| --- | --- |
| 1、15、16项 | 最多前15项参与参考频率计算；第16项不参与均值，但正频率的第16项仍会被重排成16倍新基频 |
| 频率正、幅度10000 | 仍纳入均值，不按“幅度缺失”直接排除 |
| 频率0或负、幅度10000 | 不纳入均值；非正频率槽在后续重排中保持原值 |
| 频率0或负、幅度正常 | 纳入均值，允许0或负的贡献；不能仅平均正频率 |
| 中间若干槽被排除 | 每项仍除原槽序号`k+1`，不将剩余槽压缩后重新编号；均值分母则是实际纳入数量 |
| 首幅度10000 | 在计算前先改为−200；单分量也能产生有效参考音高 |
| 首频率传入0或负 | 跳过新参考音高计算，保留已有cent；正的后续槽仍按保留cent对应Hz重排，首槽保持0或负，素材最近邻比较仍用首槽 |
| 首频率正，但算得均值0或负 | cent设为负FLT_MAX哨兵，重排基频取0；不沿用已有cent |

独立模型保留逐项float32转换、累加、数量除法及最终float32舍入。预期值在调用原生前计算，不从原生结果反推。

### 数值证据

**20个用例全部通过**：20个cent值、153个频率槽、153个幅度槽共326个float32逐位比较一致；各数组前后32字节保护区保持，153个自有相位槽保持零；素材选择索引符合独立预期。

- 将第15项由`15×440`改成`15×880`，独立预期均值为 `469.3333435058594 Hz`，原生cent为 `111.7313232421875`；15项和额外附加第16项的结果一致。
- 前15项保持标准440Hz谐波，只把第16项从16000改为64000，cent均为0，第16输出均为7040Hz。这同时验证“计算忽略”和“输出仍改写”两条不同边界。
- `[440,0,1320]`：中间幅度10000时预期均值440Hz、原生cent为0；幅度−20时预期均值 `293.3333435058594 Hz`、原生cent为 `−701.9549560546875`。
- `[440,−440,1320]`：中间幅度10000时cent为0；幅度−20时均值220Hz、cent为−1200。
- 首槽传入0或−220、已有cent1200时，原生cent保持1200；`[440,−880]`和`[440,−1760]`的参考均值分别为0/−220，则实际写出负FLT_MAX音高哨兵。

均值是独立模型的预测量；实际比较的是存储cent、重排后的数组及选择索引，没有声称从寄存器直接观测未舍入的均值。

## 二、过渡期间反向轨迹：完成

### 补齐的调用关系

复用 `0x158E40` 已核实的状态分流，并只新增核对其直接事件调用 `0x1570F0`。该函数反编译将第二参数误推为float；指令核对确认索引由EDX传入，**`0x157137` 每次把索引写入处理状态 `+0x5C`**。后续 `0x157307/0x15732E` 等按该索引定位步长0x850记录和素材区域。

因此，处理状态A/B不会永久绑定于初次换层时的素材。仅建立双状态后固定两份索引的模型，在第一个“回到旧层”用例中失败；确认该直接赋值后，按调用参数更新独立状态模型，完整矩阵重跑通过。没有用实测索引回填模型，也没有扩大查询到其它分支或模块。

### 动态结果

覆盖从220→440和660→440两个方向，在计数2/3/4各自返回旧层两次后继续换层，共6条轨迹；另从440出发向660/220启动过渡，再直接转向另一侧，2条轨迹。合计 **8条轨迹、52次调用**，独立模型与原生的cent、上次索引、计数、权重、状态指针是否交换及已建立状态索引全部精确一致；自有分量数组保护区保持。

| 返回/再次改变目标 | 确认行为 |
| --- | --- |
| 回到上次已提交的层 | 权重变0、计数原样保留、不交换状态指针；本次事件调用把状态A的索引改回旧层 |
| 在旧层停留两次 | 保留同一计数，不推进，也不清空 |
| 再次离开旧层，计数2/3 | 复用现有状态指针，A改指新候选、B指旧层；从现有计数继续，权重分别0.5/0.25 |
| 再次离开旧层，计数已4 | 本次直接提交候选，计数及权重归0；不重新从0.75开始 |
| 过渡中直接去旧层另一侧 | 继续原计数，A立即改指当前候选，B仍指已提交旧层；不是继续固定最初目标，也不重新交换状态 |

例如素材索引0/1/2对应220/440/660Hz，`220→440→220→220→440→440→440` 的（已提交索引、计数、权重）为：

`(0,0,0) → (0,2,.75) → (0,2,0) → (0,2,0) → (0,3,.5) → (0,4,.25) → (1,0,0)`。

另 `440→660→220→220→220` 的状态A索引为 `1→2→0→0→0`，已提交索引直到最后一次才从1变0；计数为 `0→2→3→4→0`。这解释了“目标已反向，但提交索引仍未改变”的状态，不能单看一个索引判断当前候选。
