## 一、bit13 内部 bit5 的集合统计消费

### 已确认的数据流

`0xC84F0` 的集合收尾阶段调用 `0xC86A0`，后者按统计ID选择计算。集合 `+0x20` 指向DRS帧指针数组，`+0x268` 指向六个float32统计槽。对于ID `0x62`：

`DRS Frame+0x128 → Feature+0x18（内部bit5）` 与 `Frame+0x48（double时间） → float32时间/level数组 → 0x646A0回归核 → 统计区+0x14`。

这里保存的是**level随时间的回归斜率**，不是复制、平均或新的帧level生产。结合105已验证的 level=`f32(10×f32(log10(bit2)))`，在正常秒时轴上可解释为该对数能量量的每秒变化率。没有确认其后是否再写DDI或用于某个音频控制，不能将它命名为最终Growl增益。

该分支以**特征指针非空**作为收集条件；当前核不另查外层bit13或内部bit5标志。自有数据中同时关闭两类标志、保留有效特征指针，结果仍参与斜率；NULL特征指针则跳过。该结论仅适用于这个统计入口，不推广到全部Frame消费者。

### 数值验收

[464](evidence/464_vqm_collection_statistics.json)复用415已有的独立float32回归模型，没有再次调用原生回归核来制造预期值。覆盖帧数1/2/3/4/5/8/9、完整及内部闭区间、规则/稀疏/无特征/无有效音高/常量时间/10000缺值，以及三种标志组合。

- 五个有效统计ID共 **990项**：858项有限float32结果逐位一致，132项非有限结果类别一致；不声称NaN负载位相同。
- 源帧、特征块保持原字节；统计输出仅指定槽改变，前后32字节及其它槽保持。
- ID `0x60` 在198个所测区间下没有改动输出。
- 五帧规则样例的level斜率为 `5.780292510986328`，原生及独立模型完全相同。

无特征时 `0x62` 输出0；只有一个有效点或相同时间等退化输入可产生NaN。回归核还有“y等于10000跳过该项，但均值分母仍取传入数量”的既有约定，本轮保留该行为，不擅自修正成通用统计库算法。

## 二、音高统计槽及元数据边界

同一 `0xC86A0` 的已验收映射如下。音高输入为DRS帧 `+0xF0`：bit31置位按cent读取，否则仅正Hz经 `1200×ln(Hz/440)/ln(2)` 转float32 cent；不大于负FLT_MAX哨兵的值不进入有效集。

| 统计ID | 输出偏移 | 计算/条件 |
| --- | --- | --- |
| `0x5D` | `+0` | 有效cent顺序float32累加后除数量；无有效值输出0 |
| `0x5E` | `+4` | 最后有效cent减最先有效cent；没有有效值输出0 |
| `0x5F` | `+8` | 最后时间减开始时间，再加传入时长参数，最终转float32；时间差在double中计算 |
| `0x60` | 无 | 本入口不写输出；不能给统计区`+0x0C`虚构含义 |
| `0x61` | `+0x10` | 有效cent对float32时间的回归斜率，正常单位cent/秒；退化区间可非有限 |
| `0x62` | `+0x14` | 上述内部bit5的时间斜率；没有特征时为0 |

464的五帧规则样例依次为均值−390 cent、端点差500 cent、时长约0.121秒、音高斜率11739.6865234375 cent/秒。均与独立模型相等。此处是自有混合Hz/cent输入，不是新的V4X成品统计。

**制作边界：** `0xC84F0 → 0xC86A0` 已明确为集合统计调用；不能仅因均值与287的DDI pitch2吻合，就认定它是VQMp原制作写入链。通用part读取器 `0x10B1A0` 对 `part+0x160/0x164` 读取已有四字节值；正常及备用格式有不同后续字段顺序，但未见它计算这两个值。读取已有值不算生产赋值证据，本轮不继续扩大搜索。

## 三、Growl 的 pitch1 消费与选择规则

### 入口链与被补正的参考频率计算

`part+0x160（pitch1） → 0x15DFB0 → 步长0x850素材记录+8（Hz） → 0x158E40选择器`。记录仍保持原顺序；本轮没有获得pitch1原制作公式。

选择器不是简单拿传入的首频率直接作最近邻。它先覆盖工作帧首频率；在所测的正常分量标志条件下，`0x158F90..0x158FF8` 对前最多15个分量收集 `frequency[k]/(k+1)`，各项转float32、顺序累加并除有效数量，再调用 `0x1589D0` 转cent。经 `0x159027..0x15904A` 转回Hz后，正频率槽重排成其谐波倍数，再用首槽Hz选择素材。

收集条件在指令中是“频率为正，或对应幅度不是缺失哨兵”，不能简化成仅正频率。**本轮动态覆盖的是两个正分量；15项上限及非正频率条件是静态确认，尚无对应动态边界验收。**

这个计算在反编译文本中丢失了部分浮点累加。首版独立模型错误地仅使用传入Hz，首个对照得到原生390Hz、预期340Hz，断言失败；限定查看当前函数指令后确认上述平均过程。改正独立模型并重跑全部测试后通过，没有修改DLL或将原生观测值作为预期输入。

关键反例：首槽传入340Hz、第二槽保持880Hz时，参考值为 `(340+880/2)/2=390Hz`，测试确实选择390Hz记录；不能把这一过程误说成直接选择340Hz最近层。

### 已验证的选择与状态

| 规则 | 关键RVA/数据 | 465的动态覆盖 |
| --- | --- | --- |
| 最近距离 | `0x1590D8..0x159116`；严格小于才更新候选 | 未排序记录、等距及重复pitch；等距保留原序中最早项 |
| 相邻索引滞回 | `0x159121..0x1591DA`；上次索引在Growl`+0x60` | 向后索引的比率小于0.75保留旧层；向前索引的比率大于0.25保留旧层；等于门槛允许换层 |
| 模式重置 | `0x158EE9..0x158EF7` | mode小于2先清上次索引；mode=1连续调用不能验证历史滞回 |
| 描述符锁层 | `0x1591DC..0x1591EF`；描述符`+0x40` | 标志开启且旧索引有效、增益为正时保留旧层 |
| 双状态切换 | `0x159217..0x15944F`；计数`+0x34`、权重`+0x38`、状态指针`+0x20/+0x28` | 交叉运行新旧状态，权重依次0.75/0.5/0.25，随后归0并提交新索引；同时核对状态内索引`+0x5C` |
| 零增益 | `0x1591FC..0x15920F` | 上次索引清为−1，两个状态active清零；再次正增益可重新选层 |

[465](evidence/465_vqm_growl_pitch_selection.json)共 **10个场景、34次受验调用**，另有1次复用夹具的基线调用。参考频率、旧层索引、切换计数及权重、已建立状态的素材索引全部与独立模型精确一致。复用的原工具保持不变；仅在新验证器的Python绑定层接入自有描述符，原生函数和指令保持原样。

例如记录220/440/660Hz：从220Hz层出发，350与384Hz仍保持旧层；385Hz恰到0.75门槛后开始过渡，连续四次的计数/权重为 `(2,.75)、(3,.5)、(4,.25)、(0,0)`，第四次才提交440Hz层。反向440→220Hz在275Hz的0.25门槛表现对称。相邻关系按**记录索引**判断，不是先按Hz排序。

选择夹具使用明确分配的0x80字节描述符，覆盖读取到`+0x40`的标志；原通用夹具只分配0x40，本轮没有据它的越界字节推断锁层。该说明不追认或撤销旧证据的其它结论。
