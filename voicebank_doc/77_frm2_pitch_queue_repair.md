2026-09-15。重新核对 Ghidra 当前 `/v6/DSE.dll`，x86-64，基址 `180000000`，
SHA256 `7a4965bd377dbc2b08710e807ae1345b67d9fff6579ca0c01a769f744366f5b5`。

## 新增模型和观察方法

`frm2_pitch_repair.py` 实现默认五帧窗口的修正，输入为 Hz。
窗口使用队列索引 1..5；第5帧已经经过候选和清浊门限，修正主要写索引2..4。
模型分别保存 Hz 和 cents，以保留原生部分比较使用前一次修正前差值的行为。

规则包括起音跳变拒绝、局部峰谷和八度修正、连续性插值、较大跳变的 Hz 插值、
尾端跳变拒绝，以及孤立的1/2/3帧有声片段删除。它们按顺序生效，不能作为互斥分类处理。
插值权重为 float 0.33/0.66，不是精确三分之一/三分之二；也不能全部替换成 Hz 或 cents 的同一种插值。
保留一个原生空区间条件 `1300 < difference < 1100`，不擅自将它修成可达范围。

`probe_frm2_pitch_queue.py` 包装原有 step 回调，在调用前后读取同一批帧对象，
避免把队列轮转误当成数值修改。观察器不替换候选或修改输出，并与无观察器整批结果严格比较。
只在当前帧新获得 bit9（F0字段存在）时运行修正预测；其余步骤断言五帧F0不变。
不能对每个外层 step 都运行修正：外层还有未进入音高分析的推进阶段。

## 扩大验证

信号频率为 50、75、110、147、196、220、294、330、440、660、880、1000 Hz，
每个频率分别测试稳态、渐入和中间静音，共36组。每组0.25秒、44.1kHz，五个谐波。

| 项目 | 结果 |
| --- | ---: |
| 外层 step | 4,896 |
| 实际音高/修正阶段 | 1,764 |
| 五帧比较值 | 8,820 |
| 最大音高绝对误差 | 0 Hz |
| 旧帧正音高被删除 | 580 次 |
| 观察器与完整基线比较 | 36/36 完全一致 |
| 新增正帧数减删除数与最终有声帧数 | 36/36 相等 |

受测事件包括17种标签。其中实际发生 `extremum_bridge` 2次、`octave_extremum` 1次、
`octave_plateau` 1次，既包含删除也包含数值修改。其余未触发分支不能据此宣称动态验证完成。
事件标签只是模型中规则的位置，不是声学材料分类；一次推进可产生多个事件。
