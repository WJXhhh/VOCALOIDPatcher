## 为什么逐帧比较会遗漏规则

旧669帧集合的242个不匹配谐波全部低于3500Hz，最高3478.8721Hz。
它们不是相邻槽位交换、简单相位取反或加π。直接用当前共振模型相位也不能解释。

分析侧`0xd2cc0`内部的`0xd79b0..0xd7b74`按频率展开相位，并保留跨帧状态：

```text
d[k] = circular_difference(aligned_phase[k], wrap(current_ENV_previous_point))
if frequency[k] <= 3500 and voiced_frame_count > 5:
    if abs(d[k] - previous_d[k]) > threshold:
        correction[k] += previous_d[k] - d[k]
    correction[k] = move_toward_zero(correction[k], decay)
else:
    correction[k] = 0
previous_d[k] = d[k]
ENV[k] = ENV_previous_point + d[k] + correction[k]
```

默认threshold为float `5.183628082275391`，默认decay为float `0.2`弧度/帧。
圆周差入口`0x2afd0`只按±π比较后加减一次2π；本算法输入先通过`0x2af60`归约。
各次加减的float舍入会影响后续展开，不能只在输出端统一取模。

代码还有以下真实分支，不能任意当作拟合参数：

- 分析特征块`+0x28`超出阈值时，decay改为float π；低于100Hz时比较阈值会调整。
- 上下文`+0xbb0 == 0x200`时，decay再翻倍。
- 特征块`+0x2c`起的分类值可将threshold改为float `5.654866695404053`或`5.9690260887146`。
- 非正频率不产生包络内点；高于3500Hz时立即清除该槽位的修正量。

例如Original帧`0x983fd90`，第三、第四谐波的前帧修正量分别约为-4.636449和4.676031；
向零回退0.2后，精确解释本帧约-4.436448和4.476031的修正。
旧的模周期误差1.846737和-1.807154只是这些未展开修正量的另一种表示。

## 相位原点：80点搜索及历史平滑

入口`0xda730`会返回float相位；Ghidra将其误推断为void，并漏掉后部输出路径，
已通过调用处及返回汇编确认实际返回约定，再在独立进程原生调用。

1. 取最多`clamp(round(2000/F0),8,50)`个槽中的正频率谐波。
2. 枚举80个首谐波目标角度`-π + i*2π/80`，不含+π端点。
3. 按各候选产生共同时间偏移，对第k谐波增加k倍线性相位。
4. 将相位归约后，计算相邻有效谐波的绝对圆周差的平均值，严格较小时更新最优候选。
5. 候选写入相位历史，再根据历史连续性、锁定状态和低频幅度门槛决定返回值。

连续历史下，候选相对上一原点的差在±π内比较。旧值权重随差的绝对值从0.5增加到0.95，
区间拐点为0.15π和0.4π；锁定时权重至少为float0.96。
最终每次移动最多0.1弧度，锁定时最多0.025弧度。
不连续且已锁定时另走约0.04倍差值的路径；未锁定则直接采用候选。

首谐波比第2..10槽中、1600Hz以内的其它有效谐波高出超过20dB时，保留上一原点。
比较范围没有其它谐波时也会进入这个门槛分支，不能只按常规“平衡多谐波”情况推断。

独立公式与原生入口对照覆盖4种F0、3种谐波数、3种相位形状、3种旧原点以及
锁定/未锁定、连续/不连续组合：**432次候选搜索和432次最终返回值均零误差**。
这些测试将历史锁定状态显式设为输入，尚未验证自动锁定判据的完整状态演化。
调用者随后还会用前10个谐波与上一帧对齐相位的差值，进行另一轮共同相位调整；
因此该入口的返回值不能直接当成商业位37第一点。
