# WAV→普通FRM2：独立相位生产入口

2026-09-15。用户在文档99的协议排查后明确选择“接通独立生产实现”。本页按这一选择交付，**不宣称原生完整相位入口已修好**。

## 已接通的流程

`build_frm2_from_wav.py` 直接读取用户提供的WAV，执行已验证的源分析/独立预测、独立相位状态机、独立A/B/C与主/第二共振拟合、残差生成、普通FRM2保存、原生reader和幅度/相位消费者检查。

不再调用原生phase入口，不向其队列写入谐波，不暂时清空可选F0改写对象，也不从原生相位/ENV结果反推下帧状态。独立模型的初始差值历史明确为0。正常源分析仍使用固定DSE的调度与MKL FFT，以及本机只读FIR/查表资产；这些依赖没有被隐藏成“纯Python无依赖实现”。

输入支持单声道、44100 Hz、未压缩PCM16 WAV，长度2048样本至5秒。此限制面向研究单元且明确拒绝超限，不会静默截断或重采样。未经验证的输入若导致源模型与原生源分析不一致，会失败并保留诊断，不能把本轮四类信号通过外推为所有真人录音音质通过。

输出目录包含：

- `frames.frm2`：普通有声FRM2块串，保留源时间戳。
- `timeline.json`：所有分析时间位置、F0、是否输出及对应帧索引；无声或没有可拟合E7的位置不会被静默挤掉时间。
- `report.json`：输入/输出哈希、显式依赖、生成帧数、字段及两个消费者验证结果。

这不是DDI/DDB安装包，也不补造无声/VQM帧。普通有声流与完整声库组装的边界必须保留。

## 使用

在仓库根目录运行：

```powershell
python voicebank/tools/build_frm2_from_wav.py `
  --dll "C:/Program Files/VOCALOID6/Editor/DSE.dll" `
  --wav "你的录音.wav" `
  --output-dir "../VOCALOIDPatcher-research-work/frm2/my_unit"
```

`--pitch-seed` 默认220 Hz，源分析使用automatic模式，种子不是强制所有帧保持220 Hz。工具按固定DSE SHA256拒绝其它二进制。必须指定新的输出目录，已有结果不会覆盖。

工作进程隔离原生调用，最多运行1800秒。生成文件先落在输出目录旁的专用暂存目录；只有保存和消费者检查成功才发布整个结果目录。失败/超时不发布目标目录，诊断及部分暂存结果保留在同一研究目录。不会使用Windows Temp。

## 本轮验收

四个真实PCM16 WAV输入：220 Hz稳态、起音、静音间隔、以及220→330 Hz拼接变化。共219个分析时间位置，生成175个普通帧：37、37、22、79。

364,945项字段读回、175项F0读回、53,235项幅度消费、19,250项相位消费全部零误差。已验证已有目录拒绝覆盖且报告不变、立体声拒绝、全静音不发布目标目录。

稳态输入重复生成的 `frames.frm2` 字节完全一致；四个输出的块边界、帧数、时间线映射和报告哈希均已核对。旧的自生成稳态源分析入口回归也通过。完整机器证据见[验收记录](evidence/100_independent_wav_build.json)。

## 可维护性与后续范围

源分析辅助函数新增可选PCM输入，旧的自生成信号调用保持兼容。生产工具复用已有独立模型，避免另写一套数值公式；原生原始谐波仍仅作源预测的核对目标。研究探针在私有对象上安装观察回调，但不替换计算输入。
