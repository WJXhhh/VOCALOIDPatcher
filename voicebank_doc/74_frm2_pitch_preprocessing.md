# 模式4频谱预处理与准备PCM至评分的独立衔接

2026-09-14，DSE哈希同文档73，当前Ghidra目标已核对。
本轮补齐文档72的标量谱到文档73自相关输入之间的缺口。
预测从原生准备PCM出发，后续窗、核、谱、预处理、自相关均由独立模型计算。
原生中间数组只用于逐层比较，不再输入自相关预测。

## 预处理规则

模型：`frm2_pitch_preprocess.py`，针对当前默认变体、扩展因子1及实际H=512路径。
以下叙述省略的float中间舍入均已在工具中显式保留。

1. 对标量谱取float平方根，再计算`20*log10(amplitude/32768)`；输入为0时写-200。
2. 扫描局部峰和谷。遇到谷时，以之前记录的峰位置做加权平滑，生成这一段的背景值。
   不是直接连各谷的幅度，也不是通用滑动平均。
3. 平滑基础半径由两项带宽之和换算为bin：带宽下限均为80Hz，另外分别比较4和5个bin的频宽。
   在700Hz以下，半径随峰位置缩短。三角形因子乘低端`min(abs(bin)/3,1)`，再对乘积平方。
   负索引反射，高端裁剪；满足缓存条件时分母仍用完整对称权重和，不能重新按截断区间归一化。
4. 该背景值填充从上一谷到当前谷的区间；低端还有以50Hz对应bin为中心、幅度6dB的三角调整。
   上一谷附近三个点用四分之一步长衔接，末尾延续最后填充值。没有有效谷时背景全0。
5. 从对数谱中减背景并截断到非负；首个局部谷之前若起点高于后段最大值，按比例压低前段。
6. 依据原始对数谱的全局最大值做频率加权：弱项门限在150Hz以下距最大值30dB，
   150–300Hz线性过渡到40dB，300Hz以上为40dB；低于门限时按差值衰减。
   距最大值20dB以内的强项另作线性增强。
7. 把首项改为加权结果的最大值，第二项改为其float 0.9倍，第三项置0，最后所有项乘10。

每层分别与估计器中的原始对数谱、背景数组和最终+c8处理后谱比较；
没有通过修改输出或放宽预处理误差来使它通过。

## 串联验证

三个自有五谐波输入110/220/440Hz，采集时刻首次越过0.03/0.06/0.09/0.12/0.15/0.18/0.21秒，
共21份准备PCM。它们来自完整原生批量入口，观察器与无观察器的完整批量结果逐帧一致。

独立计算顺序为：

```text
准备PCM → 窗/核构造 → 实核卷积与标量谱 → 对数/背景/加权 → 自相关评分
```

| 比较项 | 数值数量 | 最大差 |
| --- | ---: | ---: |
| packed频谱 | 21,504 | 0 |
| 标量谱 | 10,773 | 0 |
| 对数谱 | 10,752 | 0 |
| 背景数组 | 10,752 | 0 |
| 处理后谱 | 10,752 | 0 |
| 自相关评分 | 10,752 | 1.1920928955078125e-7 |

预处理三层合计32,256项全部严格一致；自相关仍保留文档73的实际Nyquist规则及标准规则负对照。
评分预测输入来自独立预处理结果，不是捕获的原生+c8数组。

扩大时刻范围时，一份尾部附近的220Hz窗口的独立诊断主峰位于约218.024Hz，超过原先内部稳态窗口
的一个频点诊断范围。该样本没有删除，报告保留`diagnostic_within_one_bin=false`。
密集采样模式将主峰诊断作为观测值，不把它当作原生等价门限；所有原生逐层等价检查仍照常断言。
原来的三个内部时刻仍保留原诊断门限，默认命令行为未改成放宽检查。

## 完成边界

文档73所述“原始谱至处理后谱”缺口在本次默认路径与样本集合中已闭合，
不再需要原生背景/加权结果作为模型输入。
但本链从准备PCM开始，尚不是从原始录音、重采样、预滚动到最终F0的完整独立实现。
候选筛选/插值、清浊门限和跨帧修正仍未完成，也没有宣布模式4的最终音高反例被修复。
其它变体、扩展因子、窗口及一般录音条件不能由这21份数据替代。
