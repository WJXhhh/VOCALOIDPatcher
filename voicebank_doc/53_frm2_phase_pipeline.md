# 普通FRM2：相位状态机的连续原生验证

2026-09-13，仍属于任务表“普通FRM2的精确数值语义”。

本轮把文档52的分散原点/局部修正检查接成了**从零状态连续运行的相位模型**。
48组自有输入、3,144次原生帧推进，2,856个有声帧的90,344个相位ENV点全部零误差。
这完成了受测输入上的分析侧相位子流程；**不是商业位37完整制作与保存流程复现**。

## 验证方法及边界

继续使用已核对的DSE.dll：SHA-256
`7a4965bd377dbc2b08710e807ae1345b67d9fff6579ca0c01a769f744366f5b5`，
Ghidra目标`/v6/DSE.dll`、x86-64、基址`0x180000000`。下文地址均为RVA。

直接将配置ID `0x7d`（配置对象`+0x5a8`）设为1，并沿用默认PCM分析配置，
会跳过原来的谐波分析路径，在首个有声帧缺少谐波/相位数组。
这是当前实验配置不能直接贯通完整PCM分析的证据，不代表已确定所有有效配置均不可用。

新工具[verify_frm2_phase_pipeline.py](../voicebank/tools/verify_frm2_phase_pipeline.py)
在独立子进程构造分析器，通过**该自有对象的私有虚表副本**观察每次原生step。
每次step前，为队列帧填入自行生成的频率、幅度和原相位；跨帧内部状态由原生保留。
没有修改DLL代码、DLL全局虚表、Ghidra项目或Editor。
对象资源随短进程退出回收；每例有60秒超时和10,000次step上限。

Python模型独立保留原点、锁定、上一对齐帧、局部修正和差分历史，初值为零。
模型读取原生F0与分析特征作为**输入**；不读取原生相位输出或ENV作为下一步预测状态。
这与文档52通过保存ENV反算状态的条件验证不同。

## 本轮补齐的规则

### 自动锁定

`0xda730`始终先将80点搜索所得候选推入历史，再判断锁定。
原生构造器分配15个候选历史槽；处理次数大于10后，检查此前F0历史的正值连续性。
取最近10个候选，按六种圆周切口分别展开，选择平均绝对圆周偏差最小的方案。
平均偏差不超过0.2、最大偏差小于0.35时锁定。比较及累加的float舍入见实现。

锁定后在本入口内不会自动解锁。首谐波幅度门槛只阻止返回原点移动，不阻止候选历史更新。
新增900组分布、临界偏差、历史计数、静音位置和已有锁定组合；
900个锁定状态及返回相位全部与原生一致。文档52的432组搜索/平滑检查仍全部零误差。

### 第二轮整体对齐

调用者`0xd75f4..0xd7850`先按所选原点，对第k槽加k倍共同相位偏移。
从连续有声的第二帧开始，用前10个槽中、当前与上一帧频率均为正的谐波：

```text
shift = 0.9 * mean(circular_difference(previous_aligned[k], aligned[k]) / (k+1))
aligned[k] = wrap(aligned[k] + (k+1)*shift)
```

float累加顺序及各次舍入都保留。随后把这份对齐结果保存为下一帧参考；
它位于局部跨帧修正之前，不能用已展开的ENV代替。

### 特征决定的局部修正分支

文档52的局部状态转移保持不变，本轮将分支选择写成确定规则：

- 默认回退量为float0.2。特征`+0x28`超出正负阈值时改为floatπ。
  F0≥100Hz时阈值1.5；更低时为`1.5 + 2*min(1,(100-F0)/50)`，保留float舍入。
- 步长`+0xbb0 == 512`时回退量翻倍，因此分别为float0.4或float2π。
- 从特征`+0x2c`起寻找第一个大于-100的值。
  其绝对值小于2时，跳变阈值为`5.9690260887146`；等于2时为`5.654866695404053`；
  大于2或没有找到值时为`5.183628082275391`。

本矩阵实际执行了默认和最大跳变阈值以及四种回退量；绝对值恰为2的分支来自汇编，
尚未由这个PCM特征集合触发。不能把“选择逻辑已确定”写成商业59次例外已独立复原。

### 静音及空槽

无声帧会清零连续有声计数，但保留原点、锁定、候选历史和上一对齐帧。
再次起声时先清零局部修正；首个有声帧跳过第二轮整体对齐，前5个有声帧不累积局部修正。
处理帧计数仍跨过无声帧，因此自动锁定不能直接改用连续有声计数。

非正频率槽不写ENV内点，也不更新该槽差分历史。原生差分数组并非所有槽初始都有定义，
验证器只比较已经被有效谐波写过的差分槽；永久空槽的未初始化字节不是数值语义。

矩阵：稳定相位、变化相位、缺失谐波、首谐波幅度门槛、变化相位跨静音、
已锁定稳定相位跨静音，乘以80/220Hz、256/512步长、特征分析开/关，共48组。
