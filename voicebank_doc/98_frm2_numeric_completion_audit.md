# 普通 FRM2 精确数值语义：按原任务验收

本页按用户指定的四项验收：**谐波幅度标度、两个ENV、位22三个头参数、第二共振列表**。验证对象为本机V4X普通STA/ART帧及固定版本DSE；不扩展为所有历史版本、任意ENV flags或整套商业制库流程。

## 数值契约与证据

| 原任务子项 | 已确认的数值含义 | 对应证据 |
| --- | --- | --- |
| 谐波幅度标度 | 对数幅度以32768为线性基准，20log10；保存数组与模型重建值可以不同。共振幅度读入后按32768×exp(v×ln(10)/20)恢复线性值，具体float顺序见实现 | 文档45、49；自有PCM归一化/谐波验证；本轮保存、原生读回和幅度消费者联合回归 |
| 两个ENV | 普通bit23是模型的对数幅度残差，规则网格线性插值；普通bit37是相位弧度修正，四点Lagrange形式插值，经频率映射及周期归约后加至输出相位。bit37不能当作谐波幅度包络 | 文档49的1,608点插值、64项真实相位消费者对照；文档51的669帧、492,384个bit23网格点；文档95—96的插入和历史边界 |
| bit22三参数 | A、B、C表示 A+B×(exp(f×C)−1) 对数幅度基线；含估计前整谱抬升、参考选择、限幅与两遍原地跨帧平滑 | 文档51：8库856,983个普通帧全部通过，A/B容差1e-4、C容差1e-9；文档86独立估计与拟合；本轮72项估计回归 |
| 第二共振列表 | 中心频率、对数幅度、带宽；与主列表在线性幅度域求和后转回对数域。DRS分析侧解析响应与DSE运行时二维查表必须区分，第二列表不能推定与主列表有相同的相位作用 | 文档48—51的原生角色与模型对照；936项单共振、648项完整模型测试；文档86的独立优化、精修和残差；本轮两列表保存/消费回归 |

形式化幅度关系为：

```text
model(f) = A + B*(exp(f*C)-1) + 20*log10(sum(response_j(f))/32768)
output(f) = model(f) + E23(f/22050)
```

这表示量的关系，逐步float舍入、下限、带宽夹紧和表坐标边界以 `audit_frm2_numeric.py`、`frm2_dse_model.py`、`frm2_resonance_optimizer.py` 及文档49/51为准。DSE查表常量仍只读自本机DLL，不在仓库分发；已知查表消费规则不等于恢复了厂商生成常量表的流程。

## 本轮最终回归

2026-09-15验收通过。36个自生成信号中25组产生可拟合有声E7，共479个普通帧；全部以当前模型重新拟合、生成非零相位ENV、保存并交给原生reader及两个消费者验证。993,885项字段、479项F0读回、143,201项幅度消费、52,690项相位消费均零误差。加入两节点保护后重新读取同批文件再次通过，未重新使用旧模型结果作预测。

[本轮机器证据](evidence/98_numeric_completion_audit.json)包含四项逐项判定、源信号及保存/消费回归、两节点边界和参与实现的文件哈希。所有生成FRM2保存在仓库旁研究目录，没有放入仓库。

因此，原表“普通FRM2精确数值语义”的四项可按本页明确的版本和字段范围验收完成。完整商业制库、全量音质或所有版本兼容未在本页宣称完成。

本轮另行重跑1,608项ENV插值和64项相位消费者，均零误差；72项bit22数组估计最大误差7.58e-13。已复核文档51机器证据中的STA/ART帧数及全部匹配数，也核对了旧反例统计与最终通过指标不是同一字段。

## 两节点相位ENV的确定性边界

本轮补查了此前仅注明DRS/DSE不同的两节点情况。DRS mode3退化为线性；DSE mode3会读取已分配容量内、逻辑节点数之外的第三个y。对(0,-3)、(1,9)，把这个未保存值设为0、12、-12，x=0.5分别得到3.5625、2.8125、4.3125。文件内两个节点没有变化，因此其内部插值不能仅由保存内容确定。

新增 `verify_frm2_two_node_env.py`：三组节点值×三种容量内第三值，1,809项DSE求值和1,809项DRS求值分别与显式内存条件下的模型及线性模型零误差。写入前检查容量至少三槽，始终保持逻辑节点数为2。独立 `interpolate(..., cubic=True)` 现在拒绝少于3节点的输入，防止以重复端点公式伪装成精确DSE结果。常规非零相位ENV使用至少3节点；端点和两节点线性频率映射不受影响。

这项边界是对实际数值行为的结论，不是一个未证明正确的两节点替代算法。

## 保留的制库工程边界

- 正常PCM直接启用0x7d的原生完整相位入口未接通；文档97的24组对照已定位两类缺失输入故障。受控重放有明确输入适配和初始历史，不能称为未经适配的完整原生生产。
- 商业预设选择、录音及标注、所有分析模式、纯Python FFT敏感反例、完整音质及宿主验收仍未完成。
- 本机位22做过全部普通STA/ART帧验收；bit23的669帧是分层样本，不能写成全部商业帧验收。
- C#构建器是否接入全部研究模块属于后续集成工作；本轮未改补丁、未部署、未启动Editor。

以上事项保留为制库研究待办，不反向改变已确认的物理字段、数值单位、插值规则和消费者公式。本页的验收范围始终对应用户原表这一大块的四项内容。
