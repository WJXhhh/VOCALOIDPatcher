## 窗函数与归一化

窗生成入口 `0x4c250`。一般目标是窗系数和约为 2，因此配合未归一化 FFT 可恢复
正弦的峰值幅度；实际系数仍须按每种算法的浮点顺序计算，不能简单统一乘 `2/N`。

| ID | 解析窗规则 |
| --- | --- |
| 0 | Hamming：`0.54-0.46*cos(t)` |
| 1–7 | Kaiser，β 分别为 π 乘 1.7、1.8、1.9、2、2.5、3、3.5；I0 使用有限级数 |
| 8、9 | 三项余弦窗；参数与精确累加顺序见独立工具 |
| 10 | `0.47-0.45*cos(t)-0.01*cos(2t)-0.01*cos(3t)` |
| 11、12 | 四项余弦窗 |
| 13 | 三角窗；偶数长度的中心覆写与归一化计数有特殊行为 |
| 14 | 矩形窗 |
| 15 | ID10 的非线性角度版本，指数约 1.94640260433，最终端点置零 |

普通余弦角度 `t=2πi/(N-1)`。Kaiser 使用自己的半窗镜像布局，偶数长度中点重复。
ID10 的导数开关非零时，分子换成负解析导数，分母仍使用原窗系数和的一半。
其它 ID 在本矩阵中忽略该开关。FFT 入口 `0x4e8e0` 明确要求非导数窗；不能把其
其它参数误当成窗导数开关。

查表分支用于 ID0–9、11、12 且 `N<=10001`。每行10001个float，ID11起行号减1。
定点采样步长是 `trunc(10001*65536/(N-1))`，索引为
`(32768+i*step)>>16`，随后按实际采样和归一化。这里是10001，不能擅改为10000；
末端可能采到下一行首值。该分支与解析窗不必逐点相同。

ID13 偶数长度的峰值在镜像时被覆写，但其值已计入归一化累加器。例如 N=32 的
最终窗和为1.875。独立实现保留这个实际行为，没有把它“修正”为2。

验证长度31/32/63/64/127/128，覆盖偶数、奇数、两种生成分支和导数开关。
公式、float/double 舍入顺序都在
[`verify_frm2_analysis_windows.py`](../voicebank/tools/verify_frm2_analysis_windows.py) 中。

## FFT 的实际缓冲区契约

有效入口 `0x4e8e0` 调用 MKL `DftiComputeForward`。独立 radix-2 FFT 验证了
DC、交替正负信号、脉冲、带斜坡的正弦、固定种子噪声，长度31/32/33/63/64/65，
倍数0.5/1/2及居中开关。

FFT 长度由单精度计算 `(N-1)*factor-1` 后的整数位长决定，并上限131072；
N=33、factor=1时实际为32，不能假定总是向上补至覆盖全部输入。

- 不居中：float乘窗，超过FFT长度的部分截断，其余补零。
- 居中：按 `(N-1)//2` 分别放到缓冲区首尾，奇偶长度有不同的末端舍弃。
- 倍数小于1或窗长大于FFT长度加2时：循环折叠并float累加；偶数长度中心参与两次。

完整索引规则见工具 `prepare()`，已用复数频谱对照，不仅检查幅度。
复数输出采用 CCS：`Re0,Im0,Re1,Im1,...,ReNyquist,ImNyquist`。

**标量输出不是统一的功率谱：**首项为 `abs(Re0)`；内部为float舍入的实部平方加
虚部平方；末项却读取 `abs(Im0)`，而正确 Nyquist 实部仍在复数输出的相应位置。
因此谐波分析不能把该缓冲区从头至尾都按同一种功率标度解释。

另外，旧 helper `0x519a0` 在这份 DLL 中没有执行FFT，而是直接把乘窗时域缓冲区
当作打包频谱。三个单位脉冲共51个频点有48个不符合DFT。这是该哈希二进制的
执行结果，不能引用此 helper 证明正常分析FFT，也不推断所有分析路径都失效。

## 单帧拟合的完整调度

完整入口 `0x71e00(frame,set,maximum,spacing)`，set0验证顺序如下：

1. 移除旧主列表，解除旧第二列表/曲线关系，分配主列表，估计A/B/C。
2. 主列表数为 `trunc(maximum/spacing)`，分配器上限25。
3. 第一主共振初值为 `min(500,2*F0)/0/240`；第二个为 `1500/0/260`；
   后续中心为 `k*spacing+300`，带宽为 `200+center/22050*800`。
4. 分配一个第二共振，初值 `250Hz/0dB/350Hz`。
5. 两轮处理：倒序逐个优化主共振，最大移动300Hz；按中心排序；校准第二共振，
   该调用关闭几何优化。
6. 调用 `0x70f10` 精修：再次校准第二列表、主共振150Hz移动拟合、重叠/顺序修正等。
7. 调用 `0x763b0` 生成残差ENV，入口实际连续调用两次。

三个F0×三个spacing×三种自有幅度形状×是否提供谐波数组，共54组全部通过。
参见 [`verify_frm2_fit_schedule.py`](../voicebank/tools/verify_frm2_fit_schedule.py)。
`0x6f770`、`0x6de40`、`0x70f10`的全部搜索细节仍使用原生实现；文档50已独立验证
其中带宽、幅度、中心网格搜索的平方误差目标及第二列表校准分支。

## 跨帧处理并非只平滑 A/B/C

完整入口 `0xc1610(region,set,maximum,endpointMode)` 的 set0 数值流程已独立复现：

1. 先把旧曲线在各共振中心的值加回两列表幅度，使其进入实际对数幅度基准。
2. A/B/C按文档51的三点边缘、五点内部规则，各做两遍原地平滑。
3. 第二列表依次平滑幅度、中心、带宽，各两遍。幅度/中心边缘用三点；带宽边缘
   使用四点，内部仍五点。不同字段的累加顺序不同。
4. 主列表幅度、中心各两遍。`endpointMode!=0`还在每遍中心处理前更新首末帧中心。
5. 若该开关开启，第一主共振带宽先变为float的
   `0.2*原带宽+0.8*整段第一主共振最小带宽`，最小值累加器初始为1000。
6. 主列表带宽仅一遍，边缘四点、内部五点。
7. 在新的中心处减去新的A/B/C曲线，再生成各有声帧bit23。

幅度平滑发生在解除曲线关系之后，不能直接对最终保存的列表相对幅度求均值。
第二列表中心和带宽使用不同滤波规则，二者原来线性相关也不保证处理后严格相关。

独立工具 [`verify_frm2_resonance_temporal.py`](../voicebank/tools/verify_frm2_resonance_temporal.py)
覆盖1/2/3/4/5/9/25帧、1/3/22个主共振、1/2个第二共振、开关0/1，共84组。
本矩阵每段内列表数量固定；数量变化、缺少模型标志及非有限输入未作为已验证范围。

## V4X 预设观察，仍不能唯一恢复制作设置

沿用文档52保存的669帧标识：所有帧有22个主共振、1个第二共振。
`spacing=1000`可产生22个主共振；但数量本身不能唯一确定原始spacing。
旧harness用F0作为spacing时，数量与这些商业帧吻合 **0/669**，因此旧实验的
共振列表不能当作已匹配商业预设。

第二共振的中心/带宽：432帧为200/200，219帧为250/350，18帧为其它值。
两个主要家族在同一声库内也会出现，不能仅归因于声库版本不同。
候选 `bandwidth=3*center-400` 在665/669帧内误差小于1e-4，最大反例19.3739Hz；
不把剩余中间值硬归为简单线性插值，也未声称已识别初值选择条件。
