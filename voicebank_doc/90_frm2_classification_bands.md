# 启用特征时的四十频带生产计算

接续[89](89_frm2_source_phase_producer.md)。本轮确认启用特征后的分类输入不是固定常量。
80 Hz 稳态样例的87次输出中，6次没有大于-100的有效项，其余选择值随帧变化，
例如 -96.08659362792969、-94.85595703125。原相位模型仍逐帧零误差，
但不能因此用固定阈值替代分类生产算法。

实际 step 仍为 `0xd2cc0`；新增运行配置及选择值统计，便于区分配置与字段身份。
原生实例运行时的 `0x35/0x84/0x85` 仍为0。
通过目标元数据及函数查询定位到另一个生产入口 `0xe3640`，它先计算频谱，
再按自身模式及配置选择特征转换；不能仅搜索主函数中显式的 feature+2c 写入。
其中 `0x7b4b0` 路径产生40个频带值，后续可执行20项余弦变换。
当前证据只验证该频带内核，尚未证明所有启用配置都会选择这一分支。

## 独立数值实现

输入为功率谱、Nyquist频率及42个有序频带边界。跳过DC，按float计算每个bin的Hz。
只有严格落在两相邻边界之间的bin参与，精确命中边界不参与。
每个bin以三角权重贡献给相邻频带；两端只贡献给一个频带。
累加权重和加权功率，保留float减法、除法、乘法、顺序累加的舍入。
每带除以其权重总和，正值转换为 `10*log10(power/32768²)`；
非正值使用原生缺省下限。下限数值保存在证据文件中。

新增 `frm2_classification_bands.py` 及独立原生比较工具。
32组自有功率谱覆盖32/128/512/2048 bin、线性/非线性边界、零/平坦/随机/单脉冲谱，
共1,280个频带值，与原生 `0x7b4b0` **全部零误差**。
证据：[90_classification_bands.json](evidence/90_classification_bands.json)。

```powershell
python voicebank/tools/verify_frm2_classification_bands.py --dll 'C:\Program Files\VOCALOID6\Editor\DSE.dll' --output '../VOCALOIDPatcher-research-work/frm2/classification_bands_90.json'
```
