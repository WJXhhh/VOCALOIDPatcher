## 一、bit13内部19：默认概率分支完成

### 入口和隔离方法

此项是 `Feature+0x224` 的float概率，**不是外层bit19样本长度**。已知路径内联在 `0xFB4A0` 的模式4估计器中：`0xFF474..0xFF736`读取 `Frame+0x128` 特征指针及内部0/1/2/4/14/15，最终在 `0xFF72F` 写入内部19。默认估计器 `+0x44/+0x48` 为0。

该段没有独立函数ABI。验证器在自有进程RAM中搬移这段已定位概率指令，调整其只读常量及pow/exp调用引用，以自有Win64调用适配器设置原入口所需寄存器。仍由CPU执行该段计算及DLL原数学调用；不修改原DLL。该段共156条指令，进入前已填六个输入字段，结束于概率写入，**不执行后续音高门限/历史，也不声称执行了整个估计器**。原指令和反编译内容不保存到仓库或证据。

原范围SHA-256：`1f40b4a1d8d1f4c5d6a6c3bc99a07191d7c88c644ffc84229b998ced8060d2d6`。调用前后原DLL内该范围逐字节保持。独立预期复用未改动的 `frm2_pitch_voicing.probability`，在原计算调用前取得，未用原结果回填。

[证据467](evidence/467_vqm_probability_branches.json)和[验证器](../voicebank/tools/verify_vqm_probability_branches.py)共 **97组**：1个基线、18个阈值邻值、45个噪声/强度组合、32个五类惩罚开关组合、1个无噪声零能量对照。所有概率float32逐位吻合，只有输出`+0x224`改变，特征其它字节及保护区保持；所测输出范围约 `3.72665e−6..1`。

## 二、换层及反向过渡：实际PCM消费完成

### 自有素材和对照契约

沿用108的 `0x158E40 → 0x1570F0` 素材选择/事件路径，后接已验证的Growl混合入口 `0x158A60` 和逆变换 `0x14DEA0`。三个素材记录仍以220/440/660Hz作为选择坐标，现改为**三份不同的自有PCM**：每份65,536个float样本，由不同基频、附加频率和相位的两项正弦构成。目标谱由原生分析自有PCM生成，2049个谱槽；不填写虚假的制作字段，也不改变原生函数指令。

每个待验步骤独立重放同一段前缀，到该步才把**一层**PCM指针换成另一份频率/谐波比例不同的自有PCM。选择元数据、源FRM2、控制轨迹及前缀保持。这样，已退出层的历史残留不会被误判为当前步骤仍直接消费该层。

本轮输出检查落在混合频谱及其4096样本浮点逆变换块；还检查共享取窗缓冲。原始浮点输出未做PCM16裁切或宿主音量归一化，不能把其幅度当成已验收的播放音量。

### 验收结果

[证据468](evidence/468_vqm_growl_pcm_transitions.json)和[验证器](../voicebank/tools/verify_vqm_growl_pcm_transitions.py)覆盖108原来的8条反向轨迹，加220/440/660Hz的3条稳态对照，共11条轨迹、58个待验步骤。

| 对照 | 结果 |
| --- | --- |
| 每步基线重放 | 58/58组取窗、混合频谱和PCM逐位重复 |
| 每步逐层改PCM | 174次差分；预测当步参与的82次全部改变混合谱及PCM，每次4096个样本均有差异 |
| 当步未参与层 | 92次差分全部不改变混合谱及PCM |
| 共享取窗缓冲 | 4097样本；只在改变最后处理状态所指素材时变化，与独立状态模型一致 |
| 零混合量 | 58/58组逆变换PCM全零；该控制整个重放前缀的混合量均为0，事件选择仍照常执行 |
| 逆变换数值核对 | 每个基线块取9个位置，以混合实虚谱独立求逆DFT，共522项；全部满足 `max(1e−5, 2e−7×块最大绝对值)`，最大绝对误差0.0304718017578125。是容差比较，不是逐位相同 |

合计348次前缀重放、1,242次受验选择器调用，另有1次原夹具建立基线的调用。每步的已提交索引、计数、权重和已建立处理状态索引仍与108独立模型一致。

### 音频证据对状态规则的补齐

- 过渡权重非零时，当前候选层和已提交旧层的PCM都能改变混合结果；第三层不能。
- 回到旧层、权重归0而计数保留时，只有旧层PCM改变当前输出；不能因处理状态B仍存在就认定它继续参与混合。
- 再离开旧层时，按保留计数恢复双层消费；计数已4时直接提交候选，当前输出仅随该候选层变化。
- 在过渡中直接去旧层另一侧时，当前候选PCM立即参与，最初目标若已不在两层集合内，其当步改值不影响输出。

这些是**源PCM差分落实到取窗/混合谱/时域块**的证据，补上108仅有状态索引的限制。不是仅根据索引推断，也不是只看对象存在；不替代Editor调度、重叠相加、播放链或主观跨层音质验收。原连续宿主算法的已有离线成果345/346保持，本轮不扩大其场景。
