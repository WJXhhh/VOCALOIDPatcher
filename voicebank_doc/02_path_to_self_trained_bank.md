# 达到可自训所需的验证路线

## 完成定义

只有同时满足以下条件，才能说“有把握自训一个传统声库”：

1. 能从自有录音与自有标注开始，不依赖复制商业声库的音频或分析帧。
2. 能确定目标语言的音素表、可持续音、合法转接覆盖和录音音高层。
3. 能为每个样本生成 DSE 实际消费的声学分析数据，而不是仅替换 PCM。
4. 能构造新的 `.ddi/.ddb`，所有内部偏移、块长、索引和引用均通过独立校验。
5. 能让 VOCALOID6 传统轨道加载，并在覆盖音域、连续音素、长音、辅音、跨音高和极端参数下稳定渲染。
6. 结果可重复构建；失败样本、缺覆盖和异常分析能被工具明确报告。
7. 明确本地研究、最终使用和任何分发所需的许可/授权边界。

通过标准：能独立解析 FRM2，重新序列化后逐字节一致，且能解释合成路径实际使用的主要字段。

- [x] 恢复输出 DRS SMS 到最终 DSE5 普通 FRM2 的转换入口与字段掩码。
- [x] 用程序生成、完全自有的 44.1 kHz 谐波 PCM 生成含完整声学字段的分析结果。
- [x] 由同一 DSE 的 DRS 读取端重新载入，验证帧数、长度和树层级，并由独立 probe 验证时间、F0、掩码及主要数组边界。
- [ ] 用一段自有的真实人声录音重复分析与回读闭环。

`0x1800d9b10` 已证明 DRS 有完整的内存 PCM 批处理形态，并已在独立 harness 中实际生成 DRS SMS2。它不在 DSE 导出表中且暂未找到直接代码调用者，不能当作稳定的官方训练 API。后续已恢复普通帧的 DRS→DSE5 转换入口；harness 对合成 PCM 和外部 WAV 均能输出主掩码 `0x2000e00207`，52/52 帧通过独立字段验证。单个 `Sil↔a` outer 边界现可通过 external F0 envelope 的 0/目标值阶跃精确生成两侧 unvoiced/voiced 帧；但更一般的多音素 region、真实人声样本与 ART/VQM 生成规则仍未完成。详细字段与状态机见 `06_drs_offline_analysis_driver.md`、`07_drs_sms2_harness.md`、`12_articulation_annotation_injection.md`。

通过标准：自有录音可重复产生可读取、数值合理的 FRM2/EpR，且不借用商业库分析帧。

### M4：中文录音设计与全覆盖

- [x] 从已安装中文库的 ART 键集合求交集/并集，确认 62 音素、38 STA、2,556 条公共二音素边与 3 条产品可选边。
- [x] 还原约 2556 个双音素单元如何被录音句表压缩覆盖。
  - 不含语言约束的基线为 449 条最少 trail 或 278 个最多 12 音素的 clips；原生中文 G2PA 又把公共图精确分成 373 条音节内、2,090 条音节间、55 条静音起始和 38 条静音收尾边。双音节模型的 2,090 条提示已进一步压缩为 190 条、每条 12 个合法拼音音节的长提示，并达到 `ceil(2090/11)=190` 的严格下界；全部 2,556 条边和 407 个规范音素音节可追溯。自然汉字、秒数/呼吸和声调优化仍未完成。
- [ ] 确定 2–4 层音高的选点、时长、力度、辅音上下文和静音要求。
  - 已逐样本恢复七库层坐标与时长，得到可转调的 2/3/4 层模板；满层 ART 与 STA 共用层网格，`Sil→unvoiced` 单层样本使用 `-FLT_MAX` 无音高哨兵。已生成带舒适音域硬门槛、显式时长和 QA 阈值的三层 session，但真实歌手试录尚未验证这些时长、中心音高与力度要求。
- [ ] 建立录音脚本、自动切分候选和人工 QA 流程。
  - 190 条 ART、38 个 STA 与全部层已展开为逐 take manifest，包含 WAV 路径、目标音高、carrier、预期秒数及 pending provenance。实际 WAV 的容器、时长、削波、DC、RMS/SNR 和目标 F0 自动预检已经实现；通过 take 能展开为逐 ART/STA 源采样范围，安全切成独立 PCM16 WAV，再由 DRS 按实际 frame count 校验四类清浊、split 和 inner alignment。局部合成 fixture 已闭环；真人阈值校准、声学强制对齐、人工边界修订与全量录音仍未完成。

通过标准：录音计划覆盖目标音素图，无孤立节点；每个 DDI 单元都可追溯到一段自有录音和标注。

### M5：完整构建器与宿主验证

- [ ] 批量分析、建树、打包、校验和生成安装元数据。
  - 独立录音单元的批量 DRS 分析与帧契约已经实现，验证后的 FRM2+PCM 也能不经临时单元文件直接流式合成一份确定性多单元 DDB；同一 manifest 现可生成完整 PHDC、当前 STA/ART 和多层唯一 part key 的计划驱动 DDI。15-unit partial DDI 已通过公开解析器与 DSE 原生 loader 双重回读，两次独立构建逐字节一致；最小 V5 安装元数据也可离线生成并校验。尚未执行 7,782-unit 真人全量构建或实际隔离注册。
- [ ] 渲染覆盖矩阵：所有音素、转接、音高层、长短音、连音、无声辅音和参数极值。
- [ ] 做多轮盲听与故障归因，确认缺陷来自录音、标注、分析还是树选择。
- [ ] 记录版本兼容性、回退方案和许可证要求。
  - DSE 结果码、Editor 接受集合、本机 DSE/DNN descriptor/result 分布和官方终端用户 Authorizer 流程已记录。合法新产品公开入口包括 Yamaha partner/企业咨询，以及审查制、由 Yamaha 参与录音/制作/发行的 `VOCALOID FAN-ding`；但这些页面都没有确认接受自带传统 V5/DSE 二进制，也没有公开 CompID/serial/signing API。传统库的 SDK/QA/费用和签发条件仍需向 Yamaha 询问。

通过标准：全新环境可按文档从自有输入重建同一声库，VOCALOID6 中连续使用稳定，并有足够数据证明覆盖与音质不是偶然。
