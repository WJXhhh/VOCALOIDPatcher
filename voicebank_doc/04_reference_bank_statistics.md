# 七个中文参考库的全量结构统计

## 验证方法与边界

本轮不导出 PCM 或 FRM2 负载。`voicebank/tools/probe_ddb.py` 仅顺序读取每个顶层块的头和固定前缀，以块长跳过负载；公开 `ddb-tools` 的 DDI 解析器只用于取得 EpR/SND 引用。随后逐项检查引用是否落在独立扫描得到的块集合中。

这形成了两条相互独立的证据：第三方代码解释 DDI 对象树，本仓库探针解释 DDB 顶层流。结果只记录计数、范围、掩码和集合关系，不保存商业声库数据。

## DDI 与 SND 指针语义

各库落在 SND 块内部而非块首的样本数分别为 76、152、114、114、114、114、152，恰好等于各库 STA 样本数。进一步计算偏移差后，全部 836 个值都严格为：

```text
STA DDI pointer - SND chunk start = 2066 = 18 + 1024 * 2 bytes
```

也就是说，STA 指针统一跳过 SND 头和开头 1024 个单声道 PCM samples；ART 和 VQM 的解析引用则指向块首。DSE 装载器把 STAp 的 region 1 起点乘以采样率并取整，所得位置正是 1024 samples；结合普通单元的 2048-sample 边缘扩展，它是半窗后的持续音有效区对齐点。因此打包器至少要区分：

1. SND 块的物理起点，用于写入和块级校验；
2. STA 存在的块内业务指针，用于选择持续音所需的 PCM 区间；
3. DDI 中与指针并列的 `pcm_value_count`；它在全部 56,894 个样本中都与所属 SND 头的同字段一致。

不能把三者简化成同一个“文件偏移”。

## 帧数与 PCM 长度不变量

对所有 DDI 样本使用内联的 PCM count 与 EpR 引用数计算：

```text
STA/ART: pcm_value_count = epr_count * 256 + 2048
VQM:     pcm_value_count = epr_count * 256
```

前一公式覆盖全部 56,887 个 STA/ART 样本且无例外；后一公式覆盖 7 个 VQM 样本且无例外。结合普通单元的 hop=256 和 STA 指针固定跳过 1024 samples，普通 STA/ART 使用 2048-sample 分析窗或等价的 2048-sample 边缘扩展。其半窗为 1024 samples，正好对应 STA 的有效区对齐点。

## FRM2 内部边界全量验证

恢复三种掩码的字段图后，使用 `probe_frm2.py --scan` 再次遍历同一批 30,731,926,266 字节。与顶层探针不同，这次会继续走过每个 FRM2 的数组长度、两个 ENV、共振列表和 VQM 特征块，并要求最终游标与块尾完全相等。

- 2,573,791 个普通帧全部通过；各库普通帧总长范围覆盖 10,848–12,568 字节。
- 95,002 个无声帧全部通过；总长恒为 32 字节。
- 1,459 个 VQM 帧全部通过；总长范围为 22,186–22,370 字节。
- 没有未知掩码、未消费尾字节、ENV 内外长度冲突或共振数组越界。

此外，全部 VQM 帧都完成了完整对象解析与逐字节重新序列化，形状均为 350 个正弦分量、2049 个完整谱 bin、`0x001fffff` 特征 flags 和 544 字节特征负载。
