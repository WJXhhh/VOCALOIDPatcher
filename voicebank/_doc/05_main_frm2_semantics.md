# 普通 FRM2 字段语义与样本音高元数据

## 当前结论

本批 7 个中文传统库的普通有声帧、32 字节无声帧和 VQM 帧已经可以由独立代码完整解析。代表性普通/无声帧和全部 1,459 个 VQM 帧均能重新序列化为逐字节相同的数据；此外，三种布局在 30.73 GB、2,670,252 个 FRM2 上全部通过低开销边界扫描。M1 还不能整体结项，是因为部分声学标度与生成算法尚未解释，而不是容器边界仍未知。

最关键的声学结论是：普通帧不是不可解释的厂商 blob，而是一组谐波频率、谐波幅度、相位、F0、两个 `ENV ` 包络和两组共振参数。现阶段真正阻碍自训的重点已经从“读不懂格式”转到“如何从自有 PCM 复现这些分析量”。

## 普通帧物理布局

适用掩码：`0x0000002000e00207`，位集合 `{0,1,2,9,21,22,23,37}`。

| 块内位置 | 类型 | 掩码位 | 结论 |
| ---: | --- | ---: | --- |
| `0x00` | `char[4]` | — | `FRM2` |
| `0x04` | `u32` | — | 块总长，包含 8 字节头 |
| `0x08` | `u32` | — | frame kind；本批全部为 1 |
| `0x0c` | `f64` | — | 帧时间，步长严格为 `256/44100` 秒 |
| `0x14` | `u64` | — | 字段掩码 |
| `0x1c` | `u32` | 0–2 | 三组数组的公共元素数 `N` |
| `0x20` | `f32[N]` | 1 | 谐波频率，Hz |
| 随后 | `f32[N]` | 0 | 谐波幅度，采用对数型数值；精确标度待定 |
| 随后 | `f32[N]` | 2 | 谐波相位，弧度 |
| 随后 | `f32` | 9 | F0，Hz |
| 随后 | `ENV ` | 37 | 谐波谱包络 |
| 随后 | `u32 + 3*f64[count]` | 21 | 主共振列表 |
| 随后 | `3*f32 + u32 + 3*f64[count]` | 22 | 三个头参数与第二共振列表 |
| 随后 | `ENV ` | 23 | 残差/非谐波谱包络 |

三组 `f32[N]` 的顺序不是按掩码位从低到高：读取器先处理位 1 的频率，再处理位 0 的幅度，最后处理位 2 的相位。独立写入器必须保留这个顺序。

### 位 1：谐波频率

代表性帧的 F0 为 `391.3990173 Hz`，数组开头严格为：

```text
391.3990, 782.7980, 1174.1970, 1565.5961, ...
```

也就是 `k * F0`。到 Nyquist 以下的最后一个谐波后，其余槽位以 0 填充。该帧 `N=350`，实际有效谐波为 56 个。

### 位 0：谐波幅度

数组与频率一一对应，已用频谱数值和 DSE 的指数变换确认它是对数型幅度。未使用槽位以 `10000.0` 作为哨兵。是否严格采用 dB、自然对数或某个内部缩放常量仍需沿消费者完成数学还原，因此构建器暂时不能自行选择标度。

### 位 2：相位

有效槽位位于约 `[-π, π]`，未使用槽位为 0；可以确定为各谐波相位，单位为弧度。

### 位 9：F0

位 9 是线性 Hz，不是对数音高。普通帧中它与频率数组第一项相同，随后各项是其整数倍；轻量掩码 `0x200` 的 32 字节无声帧只保留该字段，并在已扫描样本中为 `0.0`。

## `ENV ` 子块

两个包络使用同一物理容器：

| 相对子块偏移 | 类型 | 含义 |
| ---: | --- | --- |
| `0x00` | `char[4]` | `ENV ` |
| `0x04` | `u32` | 子块总长 |
| `0x08` | `u32` | flags |
| `0x0c` | `u32` | 原始 float 数据字节数 |
| `0x10` | `f32[3]` | 上下界/默认值配置 |
| `0x1c` | `f32[]` | 交替的 `(x,y)` 点 |

因此必须满足：

```text
env_chunk_size = 28 + data_byte_count
```

代表性普通帧中：

- 位 37 的 flags 为 `0x01820002`，边界为 `(-20000, 20000, 0)`，共有 58 个点。`x` 从 0 到 1，第一步为 `F0/22050`，点数等于 `floor(22050/F0)+2`。它与谐波格点严格对齐，故命名为“谐波谱包络”。
- 位 23 的 flags 为 `0x00960002`，边界为 `(-100, 10, 0)`，共有 736 个点。`x` 从 0 到 1，步长为 `30/22050`。结合 DSE 的合成消费路径，目前把它命名为“残差/非谐波谱包络”；30 Hz 网格已经确认，精确能量标度仍待确认。

## 共振结构

位 21 先写 `u32 count`，再写 `count` 个三元 `f64`。代表性值形如：

```text
(784.17, 15.40, 200.00)
(1325.00, 14.92, 499.49)
```

DSE 将这些三元组构造成 `DSE5::CResonance`，第一项作为中心频率，第二项进入幅度指数变换，第三项作为带宽并被限制到 20–1500 Hz。因此可以把三项分别解释为中心频率、对数幅度、带宽。

位 22 先写 3 个 `f32` 配置值，再写 `u32 count` 和同样的 `3*f64[count]` 共振列表。代表性帧的配置为 `(-26.4824, 73.5176, -0.00008368)`，列表只有 `(200, 0, 200)`。三项头参数的生成方法和第二列表的声学角色仍未知，不能用主共振列表的解释强行套用。

## VQM 帧布局

适用掩码：`0x00000000000e22b7`，位集合 `{0,1,2,4,5,7,9,13,17,18,19}`。DSE 读取器和全部参考帧共同给出的物理顺序为：

| 顺序 | 类型 | 掩码位 | 实测形状/含义 |
| ---: | --- | ---: | --- |
| 1 | `u32 N` | 0–2 | 本批恒为 350 |
| 2 | `f32[N]` | 1 | 正弦分量频率，Hz；growl 下不再严格为 F0 整数倍 |
| 3 | `f32[N]` | 0 | 分量对数幅度 |
| 4 | `f32[N]` | 2 | 分量相位，弧度 |
| 5 | `u32 M` | 4–5 | 本批恒为 2049，即 4096 点 FFT 单边 bin 数 |
| 6 | `f32[M]` | 4 | 完整幅度谱 |
| 7 | `f32[M]` | 5 | 完整相位谱 |
| 8 | `f32` | 9 | F0，Hz |
| 9 | flags + 可变负载 | 13 | 特征块；本批 flags `0x001fffff`、负载 544 字节 |
| 10 | `u8` | 13 尾部 | 本批恒为 0 |
| 11 | `u8` | 18 | 本批恒为 10 |
| 12 | `u32` | 19 | 本批恒为 2049，与 `M` 相同 |
| 13 | `ENV ` | 7 | 第一 VQM 包络 |
| 14 | `ENV ` | 17 | 第二 VQM 包络 |

位 13 的帮助函数先读一个 `u32 flags`，再按 flags 0–19 选择固定长度子字段；位 20 在参考值中置位但不附加数据。独立解析器按 DSE 的分支表计算负载长度，不把这 544 字节误当成固定结构。其内部物理边界已恢复，但每个子字段的 growl 算法含义仍待追踪。

全部 1,459 个 VQM 帧都满足同一组 `N/M/flags/控制值`，且全部逐字节回环成功。块总长仍会因两个 ENV 的点数变化而不同，各库实测范围为 22,186–22,370 字节。

## DDI 样本级元数据

### duration

对全部 56,894 个 `STAp/ARTp/VQMp` 样本验证后，零例外满足：

```text
duration_seconds = pcm_value_count / sample_rate
```

最大浮点误差为 `2.7e-13 s`。duration 表示整个 SND PCM 负载的时长；普通 STA/ART 的 2048-sample 边缘扩展包含在内。

### 两个 pitch 字段

DSE 的 `CDBDataPhUPart` 在对象偏移 `+0x160`、`+0x164` 保存两个 `f32`：

- `+0x160` 是样本层选择坐标。`0x18010a3c0` 对它求层的最小/最大值，`0x18010a470` 读取它，`0x180113260` 用目标音高在相邻样本间插值。
- `+0x164` 是样本的实际参考音高。运行时 `0x18016fcb0` 使用常量 2、1200、440，把它转换为 `440 * 2^(value/1200)` Hz；`0x1801c4240` 也把它复制到合成工作对象。

所以两个字段都使用“相对 A4=440 Hz 的音分”，但用途不同。公开解析器的临时名称 `pitch1/pitch2` 可以保留作为物理顺序，不应解释成 ART 的“第一/第二音素音高”。

对 7 库全部 836 个 STA 样本验证：

- `pitch2` 全部等于各自所有 EpR 帧 `1200*log2(F0/440)` 的算术平均值，最大误差 `0.000266 cent`。
- `pitch1` 有 799 个在 `0.0005 cent` 内与 `pitch2` 相同；其余 37 个存在最多 `2.049 cent` 的小调整。这与“pitch1 用于可人工整理的层坐标，pitch2 保存分析得到的实际参考音高”一致。

ART 中 `pitch2` 对有声音素转接常等于全部有声帧或选定有声区间的平均音分；在转接到清辅音时会忽略部分存在伪 F0 的帧。其选区规则尚未完整还原，不能只按两个 frame-alignment 分段分别取平均。

### 其余字段

本批样本中的 dynamics 通常为 `0.6`、tempo 为 `90`；`unknown2` 为 0。运行时已经看到 dynamics/tempo 被复制到合成单元，但 `unknown2` 的消费者尚未找到。

## 独立探针与验证范围

`voicebank/tools/probe_frm2.py` 不依赖公开 DDI/DDB 代码，可对指定 DDB 偏移：

1. 完整解析普通帧或 32 字节无声帧；
2. 验证所有数组、`ENV `、共振列表的边界和块尾；
3. 重新序列化，并要求与原块逐字节一致；
4. 只输出聚合摘要，不导出声库帧或音频。

示例：

```powershell
python voicebank/tools/probe_frm2.py "C:\path\to\voice.ddb" 0x12345678 --json
```

单帧模式会完整实例化所有字段并执行逐字节回环。`--scan` 模式不实例化数十亿个浮点数，而是按同一字段图检查每个数组、特征块、ENV 和共振列表的边界，并要求游标精确等于 FRM2 块尾：

```powershell
python voicebank/tools/probe_frm2.py "C:\path\to\voice.ddb" --scan --json
```

七个 DDB 的 2,670,252 帧已经全部通过 `--scan`。逐字段序列化验证覆盖了代表性普通/无声帧和全部 1,459 个 VQM 帧。后续还应对普通帧做分层抽样回环，并从 DRS 生成端验证数值语义；结构边界本身已经闭合。
