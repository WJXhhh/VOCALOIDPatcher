# 完整源覆盖与内部推进的菱形交互

2026-10-18，在[完整源覆盖后端](transition-source-coverage-backend.md)上接入前端，尚未部署。

## 操作

- 横拖菱形：发音展开更早/更晚；首次实际拖动自动开启对应发音侧的完整素材。按住 Shift 细调。timing 锚点、过渡 Begin/Split/End、音符长度保持当前值。
- Ctrl+单击菱形或精确面板的“重置菱形”：撤掉该过渡的完整素材与 Phase，保留 timing、音量和旧 Onset 控制。面板原来的“重置此过渡”继续负责全部过渡参数。
- 精确面板显示“使用完整发音素材（音素侧）”以及百分比。完整素材可以单独开关，进度为 0 时仍可开启；关闭完整素材时保留进度数值。输入进度默认勾选完整素材，手动取消勾选的选择会被尊重，按“应用”一次提交。
- 只打开旧工程、选中、查看面板，不自动开启完整素材。单击不拖、取消或拖回原位，都不因此激活新控制或新增历史。

## 菱形的范围和含义

菱形表示主要发音侧的半进度落点。普通进入过渡优先使用后侧，例如 `s\→iE_r` 的 `iE_r` 侧；退出到静音的过渡使用前侧。已有显式单侧覆盖保持其侧别，两侧覆盖保持两侧数据。底层 Phase 沿用在各侧内部重排进度的语义。

菱形位置由有界的无量纲值计算，拖到外面也只会到达区间内的控制极限，不显示框外候选线。主要发音侧变短时，不因为另一侧更长就把控制点切去辅音上。两个输出帧可在精确面板启用完整素材；不足三个帧时不显示无法产生内部推进差异的菱形。缺失或不可表示的素材区间明确不可编辑，已有数据保留。

面板补充了当前素材状态、前后方向、细调和重置提示；小视口使用滚动容器并按实测内容尺寸定位。四种语言的 1364 个键集合一致。没有新增引擎实现细节到用户流程中。

## 提交与性能

`TransitionExpressionControl` 统一菱形和精确输入的源侧选择、启用与重置策略。鼠标按下只保存原值；拖动继续走 33 ms 合并的局部纯规划，只改变候选显示。松手后认证当前候选，通过既有统一 Part 快照提交一次历史与重渲染。Escape/丢失捕获恢复原始控制；返回原位保留原始对象，不形成隐含的完整素材开关。

命中和提示直接读取已认证的素材区间与 Coverage 列表，没有在每次鼠标移动时重建整份接点控制。新增 UI 路径不增加音频试算、原生 ABI 或工程字段。

## 验证

以 6.13.1.1 SDK 编译，在实际 6.13.1.1 / 6.13.3.1 DLL 中分别运行独立宿主。

- 每版 23 个真实渲染步骤：直接调用生产菱形拖动策略生成 `xie` 控制，再验证提前/延后、完整素材配合零进度、仅关闭素材、重置、撤销、工程保存加载、VEL、进一步压短、音量、双 Part 并发、缓存重开。四组前端表达修改逐项断言锚点与全部工作项分配保持不变；拖回原位不改变 revision。
- 两版上述 23 组 PCM 全部逐字节一致；原生源映射/增益路由零失败。
- 每版额外 40 个组合回归渲染步骤，开启 Coverage、Phase 和旧 Onset：覆盖原生移动、独立选样、删除/恢复、复制、未知数据保留、保存失败回滚、共享接点、并发和原生缓存。
- 独立 WPF 使用真实 ART 行测试命中优先级、短段选择、细调、拖回原位、两端极限、源端点完整覆盖及重置，并生成菱形绘制 PNG。模型测试覆盖旧数据无自动迁移、主要侧稳定、两帧限制、显式侧别与其它过渡保留。
- 258 项托管测试、47 项 Rust 测试通过；完整 Debug/Release 构建通过。Release 保留既有 Rust 链接器 stdout 编码警告，零错误。

证据见 [transition-expression-diamond-20261018.json](evidence/transition-expression-diamond-20261018.json)。WAV/VPR/PNG 均留在临时验收目录，没有提交生成物或专有 DLL。当前证据包含独立 WPF 和真实引擎验证；尚未替换用户编辑器中的前端，因此没有把整窗实机鼠标操作称作已验收。

复现：独立 Debug 构建增加 `-p:PatcherIsolatedValidation=true`，经 `VOCALOID_DURATION_HOST_ASSEMBLY` 指向该产物，设置 `VOCALOID_TRANSITION_COVERAGE=1` 与 `VOCALOID_TRANSITION_EXPRESSION_UI=1`，运行 harness 的 `--transition-host-probe --patcher-dse-initialization <输出目录>`。组合回归设置 `VOCALOID_TRANSITION_COVERAGE_GENERAL=1`、`VOCALOID_TRANSITION_PHASE=1`、`VOCALOID_TRANSITION_ONSET=1`。

本轮所有构建均使用独立 `--artifacts-path`。安装主补丁仍为 `D7832D4C…390DB1E`、原生 DLL 仍为 `3CB49633…30623`。后续部署需要合并主 DLL 和四份更新翻译，原生 DLL 可继续使用当前已认证版本。
