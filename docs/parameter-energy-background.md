# 参数背景能量图

设置位置：补丁设置 → 钢琴窗 → 参数背景能量图。

- 默认开启；显示范围默认 **−30～0 dB**，不透明度默认 **30%**。
- 上下限可输入整数，下限支持 −120～−1 dB，上限最高 +24 dB；始终保持至少 1 dB 的范围。不透明度支持 0～100%，设置立即生效并保存。
- **频率加权强度**默认 **50%**，支持 0～300%。0% 完全旁路，显示原始 dBFS；开启后两条线都由加权后的样本计算，以“dB（加权）”标识，目标线也以相同标尺作参考。仅分析样本，不修改源 WAV、播放、导出或参数。
- 加权采用温和的双搁架：100% 时为 150 Hz / −6 dB 低搁架与 2 kHz / +4 dB 高搁架，强度按 dB 缩放，串联响应在 1 kHz 归一化。50% 时低频约下降 3 dB、高频约上升 2 dB。100% 以上继续按 dB 增强，300% 对应 −18 dB / +12 dB 的搁架增益，再做 1 kHz 归一化。分析保留超过 0 dB 的加权峰值；白线超出显示上限时会贴顶，可手动提高 dB 上限（最高 +24），不会自动改变用户范围。系数按采样率计算，通道状态独立；没有 LUFS 的门限、积分或标准符合性含义，也不声称复现 FabFilter 内部算法。搁架系数参考 [W3C Audio EQ Cookbook](https://www.w3.org/TR/audio-eq-cookbook/)。
- **目标音量参考线**默认开启，初始 −18 dB。上下拖动最右侧琥珀色短标记可移动虚线，松开后保存到补丁配置；Esc、失去鼠标捕获、窗口卸载或改变显示范围时取消拖动。设置中可开关或输入精确到 0.1 dB 的目标值（−120～+24 dB）。仅作视觉参考，不修改音频、参数、选择或撤销历史；目标超出当前显示范围时隐藏。
- 参考线与能量曲线共享纵坐标映射，放在能量图与原生/BVL/REG 参数点的下方；文字无底块、放在虚线上方且穿透鼠标，仅最右侧 6×18 像素的边缘拖柄命中。不要再把参考层放到 `xPanel` 的高 ZIndex 或给文字添加遮挡曲线的底色。它不依赖渲染包络是否已生成，拖动期间不分析音频、不重建曲线、也不逐次写入配置。
- 参考线是独立 `FrameworkElement`，直接以 `DrawingContext` 绘制线段和字形；不创建 `TextBlock`、`Border`、背景矩形、悬浮提示或焦点装饰。命中重写只接受边缘拖柄，进入/按下拖柄时隐藏原生遗留的 `xToolTip` / `xMouseCursorGuide`，避免提示层留在曲线上。离线回归应包含会给普通文本/边框添加灰底和固定尺寸的宿主样式，以及不同 DPI 的灰块像素检查。
- 显示当前 Part 最终渲染 WAV 的 **峰值与 RMS 细线**，无面积填充、无静音底部连线。约 **1 ms 分析步长**，使用相互重叠的 10 ms 峰值窗与 20 ms RMS 窗。多声道 RMS 按功率平均，峰值取最大绝对幅度。低音量人声的 RMS 常低于默认 −30 dB 下限，峰值线可以补充显示瞬态。
- 放大时在幅度/功率域对相邻分析点连续插值，缩小时保留像素区间内的峰值，区间终点采用排他边界，不借用下个像素的首个分析点。横坐标直接通过连续 quarter/time 换算，避免先取整为 tick 造成阶梯。
- 横坐标使用原生歌曲时间轴、速度图和预发送时间，与音符波形对齐；纵坐标独立于当前参数值，右侧显示 dB 标尺。
- 普通参数、ACE 参数和 BVL/REG 均可显示。图层不参与命中测试，参数编辑、候选轨迹和播放线仍使用各自原有路径。
- 后台流式分析，单工作限流、取消、短暂去抖及有限次数文件重试。更改加权会取消旧任务、清除旧模式曲线并以捕获的新强度重新分析，防止旧任务覆盖；范围、不透明度和目标线不触发重新分析。每个窗口仅保留当前 Part 分析；每条曲线最多一百万个分析点，超长 Part 自动扩大步长；可见范围按半像素绘制，最多约 8192 个横向区间。
- 重新渲染时暂时保留旧包络，渲染完成后替换；BVL、音素音量、过渡平滑、ACE 等派生 WAV 更新也会使包络失效。同路径重渲染不复用旧分析。空 Part、切换工程、关闭功能或卸载窗口会清除或取消相应状态。
- 没有可读渲染音频或格式不受支持时不显示能量图，不改变参数和音频。

离线验证：`ParameterEnergyTests` 覆盖 PCM16/24/32、Float32、RMS 与峰值区分、增益 dB、反相立体声、静音、边界/末尾不足一帧、损坏文件、取消、加权 1 kHz 校准、100/200/300% 的 RMS 与白色峰值响应、超过 0 dB 的加权峰值、低高频响应、8～384 kHz 采样率、声道隔离、0% 完全旁路及源文件不变、非有限输入与冲激静音衰减、毫秒级瞬态、滑动窗口和放大时连续插值。

离线 WPF 绘制另行检查了普通/高倍缩放预览，以及曲线无填充、无闭合图形。参考线离线检查覆盖共享 dB 坐标、虚线与文字命中穿透、无标签底块、6 像素边缘拖柄命中、文字下方参数点可编辑、取消不提交、仅提交一次、横向滚动与范围外隐藏；实际 Editor 内的鼠标拖动仍待确认。用户已确认之前的峰值版本可见；当前细线与毫秒步长版本仍需在宿主内确认外观，并回归普通/ACE/BVL/REG 切换、滚动缩放、速度变化、Part 移动、同路径重渲染、派生音频修改、删除最后一个音符及开关/范围/不透明度调整。验证过程不启动或关闭 Editor。
