# Emotion 画布内的发音编辑工具条

2026-10-22 更新：过渡精调改为主动打开。单击段体、锁定端点，或按下可拖手柄后未移动就松开，都只选择／结束候选，不再打开精调。双击过渡或点工具条“精调”才打开面板；双击判定不抢占 Ctrl 单击重置。短过渡也可通过双击或选中后点“精调”进入。

普通悬停只显示一行时长和音量摘要，展开进度与素材说明仅在主动拖进度时显示；精调已打开时不再叠加悬停提示。面板增加关闭按钮，保留 Esc、点外部及切换上下文关闭。关闭按钮在打开时获得焦点，使 Esc 无需先点输入框即可使用。隔离 Debug / Release 构建与四份翻译键集合检查通过；真实宿主中的单击／双击、Ctrl 重置、拖动及退出仍待更新后验收。本次未部署，未改变工程参数。

2026-10-21。用户确认本轮整理的是画布左上角“音素／过渡／选样”这一排。当前源码改为深色分段工具条，并撤下独立选样时长的产品入口。

## 按钮与交互

- 音素、过渡使用单选按钮，图标和文字同时显示；蓝色填充及描边表示当前模式。重复点击当前模式不再回到另一个模式。
- 精调是右侧独立动作，只在过渡模式显示。按钮文字保持稳定，当前过渡名称放在悬停提示中，避免身份变化引起工具条宽度跳动。
- 悬停、按下、键盘焦点各有反馈；保留完整的辅助功能名称和工具提示。按钮由 WPF 处理鼠标及键盘输入，外框空白区也截断冒泡，避免落到背后的音符。
- 根据可用宽度依次隐藏分组标题、精调文字、模式文字，最后保留图标。按钮命中面积至少 32 × 28 DIP。按实际文字测量，适用于不同语言；相同宽度和模式复用测量结果。
- 工具条继续跟随原画布的水平、垂直可视偏移定位，不重建控件树。无音符但处于受支持 Part 时仍保留工具入口；AI Part 沿用原编辑器路径。
- 模式切换取消现有候选及弹出面板，只改变视图状态，不提交音符参数、撤销记录或渲染请求。现有音素与过渡编辑器继续使用原执行链路。

## 撤回时长选样方向

按用户决定，停止把“独立调节选样时长，获得所需长／短录音变化”作为产品方向。移除画布选样模式、设置开关和选样右键入口；旧配置即使保存为开启也不会恢复这些编辑入口。

历史原生评分、素材变化和 PCM 对照记录继续保留，并在相关研究页顶端标明撤回状态。此前扩大候选范围得到的跨来源变化，不能当作同一音高层内存在可切换长短录音的证明。没有把实际已有的观察改写成“引擎完全不消费时长”。

已有工程归档、恢复及渲染兼容代码暂时保留，不擅自删除保存值或改变旧工程声音。本轮没有改选样原生 ABI，也没有改 timing、音量或过渡的声学算法。
