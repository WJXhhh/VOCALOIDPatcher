# 第三段 zhong → dan 的低能量区

2026-10-22。按时间排序的第三个 Part，实际为第一轨 `part_index=1`，第 15～18 小节，末尾是 ``zhong [ts` UN] → dan [t a_n]``。本轮只做 MCP 读取、日志核对及独立 SDK 实验，没有修改、部署或重启编辑器。

## 现场与判断

开始时 MCP 工程 revision=354、无未保存修改。两个音符首尾相接：`zhong` 起点 33600、长度 240 tick；`dan` 起点 33840、长度 300 tick，VEL=105。原生音素边界分别为 `[-76,-2,195]` 与 `[-45,-4,294]`，所以 `UN` 终点和 `t` 起点均在绝对 tick 33795。中间没有额外休止符，也没有音素边界间隙。

渲染已完成，score/wave 有效，timing host 未暂停，两个目标音符没有受限记录或已保存的音素 timing 偏移。日志中有其它 Part 的既往失败和恢复，不能把它们直接归因给本处。

独立重放中，ART 调度同样连续：`UN → t` 为 4185 / 4194 / 4198，`t → a_n` 为 4198 / 4199 / 4209（Begin / Split / End）。两条 ART 在 4198 相接，没有缺失的输出区间。低能量主要位于 `t` 的分配区，符合闭塞音爆破前低能量的表现；不是渲染器漏输出了一块波形。

注意：隔离 Part 后，SDK 基准的 `UN/t` 接点与现场 MCP 相差约一帧（重放的两音符边界为 `[-76,-2,202]`、`[-38,-4,294]`）。因此下面毫秒数只属于独立重放的原始 PCM，不当作当前宿主最终后处理波形的精确测量。

## 哪些控制真正缩短这段时间

用开始时保存工程的私有副本，保留原有 tempo、音符、VEL、Opening、控制器及音素／过渡归档。隔离其它 Part 后执行对照，原件不写入。每个变体重新规划、认证并真实渲染，读取消费的 ART 帧核对计划。

低能量区按每 256 采样点一帧的 RMS 定义，在目标接点附近统计最长连续区间。阈值是测量约定，不等于“绝对静音”。采样率为 44100 Hz，一帧约 5.805 ms。

| 独立副本中的操作 | RMS 低于 −60 dBFS | RMS 低于 −50 dBFS |
| --- | ---: | ---: |
| 保存值，dan VEL=105 | 23.22 ms | 29.02 ms |
| UN→t 进度拉到 +1 或 −1 | 23.22 ms | 29.02 ms |
| t→a_n 进度拉到 +1 或 −1 | 23.22 ms | 29.02 ms |
| dan VEL 提到 127 | 17.41 ms | 23.22 ms |
| dan 的 t→a_n **音素边界**前移 2 帧 | 11.61 ms | 17.41 ms |
| 同一音素边界前移 4 帧 | 0 ms | 5.80 ms |

这里的音素边界前移，是在“音素”模式下把 `t` 与 `a_n` 之间的竖线向左拖，提前元音起点；不是在“过渡”模式下拖这条 ART 的进度菱形。把 `UN/t` 的共享音素边界后移 2 帧也得到相同的上述低能量区长度，但会延长前一个音素、推迟辅音起点，语义不同。

原因可从实现交叉核对：`TransitionPhaseMapping` 只重新分布固定时间区间内的源帧，保留分配时长和首末源位置；`TransitionExpressionControl` 对 `UN→t` 默认调右侧 t，对 `t→a_n` 默认调右侧元音。进度能改音色和发音过程，却不会缩短受保护的整个 t 区间。ART 两端的 timing 能重分配两段素材各占的时间，但仍受音素边界保护，不能越过受保护的分配点。

VEL 在本例确实有效，但当前 105 已经较高，拉到 127 只再减少一帧，故容易觉得“拉满也没改善”。音量本身不改边界；当前还存在 UN −6.2 dB、t −5 dB 的音素增益，以及 t→a_n −2.2 dB 的过渡增益，比较视觉空白时需与真正的时间长度区分。

## 验证和建议

最终矩阵共 23 次真实渲染：保存值、去过渡控制、VEL 0/64/127、两条音素边界分别 ±2/±4 帧、两处进度的正负极值、ART 两端极值及恢复。全部 timing/gain Failures 为零，实际消费帧符合计划，规划调用没有生成音频；恢复后的 PCM 与保存值逐字节一致。一个 ART 端点极值恰好等于当前值，作为不变对照保留，不算成功的参数移动。

建议先试 `dan` 内 `t→a_n` 的**音素边界向左约两帧（11.6 ms）**，保留辅音辨识，再按听感调整。四帧是本次可达的极端对照，使 t 的分配只余一帧，不作为默认推荐。若需要始终保持元音起点不动，则应改共享 `UN/t` 起点，其对前音尾部的影响需要另外试听。

目前证据指向“控制对象不同”和闭塞段的最小分配，并未证明按钮丢提交或渲染失效。若后续增加直接的闭塞长度控制，它应明确联动音素边界并给出受影响的前音／元音，不能把保持边界的进度参数改名后冒充时长控制。

研究期间用户继续编辑了其它段。结束时重新读取第三段，18 个音符的基本字段、目标两音符边界和参数仍与开始一致；实验使用固定快照，不覆盖用户后续修改。完整解决方案 Debug、独立 harness 构建均通过。原工程、现场完整快照和 WAV 均保留在仓库外，摘要见[机器可读证据](evidence/zhong-dan-low-energy-gap.json)。
