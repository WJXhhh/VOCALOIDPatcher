# 原生兼容识别：从文件哈希改为代码特征

2026-11-11。DSE/VSM 时值后端及 VDM 声库目录发现不再要求整个 DLL 的 SHA-256 命中白名单。历史 `.profile` 保留 SDK 来源和结构契约，SHA 字段不参与运行时放行。

## 识别与执行边界

`NativeCodeImage` 只读解析 Windows x64 PE 的可执行节及异常表，在有界范围内搜索嵌入的 `compatibility/native-signatures.json`。当前 41 组特征覆盖 DSE/VSM 的 37 个地址、VDM 分支及可选临时目录恢复的两个结构锚点，其中 VSM prepare 有两个函数体布局变体。

- 地址相对的调用、跳转、RIP 引用使用通配位，字段位移、指令和栈布局保持精确匹配。
- 有异常表边界的入口要求命中函数起点；较大函数另检查函数体多处窗口及已识别的私有字段访问。匹配短函数头不足以放行。
- 全局变量通过 RIP 相对引用解析，检查只读/可写/可执行节属性。调用点也动态定位，不把旧 RVA 作为扫描失败后的默认值。
- 相同辅助函数通过独立识别的调用点区分。没有足够关系消除歧义、特征缺失或引用指向错误目标时拒绝。
- 运行时确认文件就是该模块的加载路径，并复核所选代码、字段访问及用于解析地址的相对引用与内存一致。扫描过程中不写内存。

托管端将全部解析 RVA 按固定名称顺序传给 Rust。**profile ABI 为 3**，与播放时钟 ABI 分开。桥接检查模块句柄、地址数量及模块边界，第一次选择后锁定完整地址表，拒绝再次换表。Rust 的 DSE 调用、全局变量、时长调用点及 VSM prepare/cache hook 均使用这张表。旧桥接不兼容，会安全拒绝这些功能，部署时必须同时更新托管与原生 DLL。

VDM 单独识别目录分支，验证条件跳转及函数内的正向目的地，按实际位移生成等价目的地的无条件跳转。仅临时修改加载内存；嵌套 scope 复用同一模块，最外层退出或异常清理时恢复原始六个字节。

`RenderTemporaryDirectory` 不再按旧档案名称拒绝新解析结果。在实际读取私有目录字段前，另外匹配 VSM Sequence 构造/析构及字符串字段布局特征；不具备这项结构契约时单独拒绝恢复操作。

## 自动适配的范围

文件版本、签名、时间戳、调试/资源信息变化，以及保持这些代码特征与结构契约的地址移动，不需要再增加文件哈希。6.13.1.1 DSE 与 6.13.3.1 VSM 这种已知代码/结构兼容的组合也不再仅因版本组合不同被拒绝。

**代码特征匹配不能证明任意未来版本语义兼容。** 编译器改变寄存器/栈布局、私有结构发生变化、特征窗口改变或调用关系变化时仍可能拒绝，需要重新研究和验证后更新特征或引入新布局适配器。这不是对 VOCALOID 7 或未知 Editor 版本的兼容承诺；托管 SDK 引用仍有独立版本要求。

后端拒绝时保留现有工程数据读写、复制与历史行为；不把控制数据静默丢弃或当成已成功执行。

## 更新与验证

`scripts/generate-native-signatures.py` 是开发工具，接收成对的 `--sdk`、`--profile` 及 `--output`。在仓库外准备合法 SDK，开发环境依赖 `pefile==2024.8.26`、`capstone==5.0.3`；运行时没有新增 NuGet 或 Python 依赖。输出为短特征和关系，不打包 SDK DLL。重新生成后须审阅差异，不能把自动生成当作新版本语义验收。

`NativeSignatureTests` 包含移动入口、时间戳变化、字段改变、缺失/重复候选、相对引用、相同辅助函数消歧、错误映像、加载内存差异和 VDM 目的地测试。设置 `VOCALOID_SIGNATURE_TEST_SDKS` 为用 `|` 分隔的合法 SDK 目录，可额外运行真实文件的全地址解析、元数据修改及兼容组件组合验证。未设置时该项明确跳过。

宿主外验证使用 `evec_render_harness` 的 `--timing-profile-probe`、`--catalog-scope-probe`、`--timing-routing-probe`、`--duration-composition-probe`、`--phoneme-volume-probe` 和 `--transition-control-probe`。目录探针分别报告 scope 生命周期和声库数量是否增加；现有注册声库已经全部可见时，数量不变不能用于证明额外目录发现效果。

完整 Editor 交互仍需单独验收；构建与独立 SDK 探针均不能替代宿主 UI 验证。开发验证阶段未部署、启动或关闭 Editor；之后的授权部署记录见下文。
