# 借样读到了，但用户仍听不见 s

2026-10-18。用户对上一轮试听明确反馈「听不见 s」。这条反馈优先于波形、能量或素材读取成功的证据：当前方案尚未通过可辨认辅音的验收。

本轮仍是独立进程研究，未改运行中的工程、未接前端、未部署。研究入口 `--borrow-audibility-probe`。

## 固定原 timing 的增益排查

目标始终为 `s ei`，原三条边界始终为 `[-25, -13, 477]`，s 只占原生帧 3341、3342，共 11.61 ms。

通过独立研究钩子记录原生重叠相加入参。两个 s 帧的原始合成增益约为 0.3241、0.3281，并未被置零。对照原生帧输入哈希，借样保持不变，仅把这两个帧的原生贡献乘以 4、16、64。前导 Sil 帧、ei 帧和整段 WAV 均不放大。64 倍仅用于检查线性响应，不作为修复参数。

与上一轮相同的 1.474…1.492 秒窗口：

| s→7 中段 | RMS，16 位 PCM LSB |
|---|---:|
| 原借样 | 97.14 |
| 仅 s 贡献 ×4，约 +12 dB | 388.54 |
| 仅 s 贡献 ×16，约 +24 dB | 1554.09 |

输出能量按增益增长，说明信号没有被后续渲染完全吃掉或覆盖。两种供体的固定 timing 对照中，1.500 秒后的 PCM 与原版逐样本相同；+24 dB 重复渲染和最终关闭借样均精确复现。所有测试原始 WAV 均未发生 16 位削波。

但增益对照没有延长 s，也没有补上其完整发音过程。原范围只有两个 hop，上一轮绝大部分新增能量又在 4 kHz 以上。它们是可听度不足的具体嫌疑，尚不能仅凭这些数据认定增加增益就能产生清楚、自然的 s。

## 只用于定位原因的时长对照

另在一次性测试工程中，把 s 的分配改为 6、12、22 帧，约 34.83、69.66、127.71 ms。每组均先渲染不借样基准，再读 s→7 / s→a 的 s 侧完整索引区间。这里明确改变了测试 timing，所以 **不能列入保持原边界的解决方案**，更没有应用到用户工程。

三组的音素仍为 `s ei`，ei 起点和收尾不变；第一条边界分别为 -47、-80、-136 tick。各组与自己的基准逐帧核对，来源映射、stage、素材元数据、排程和两种标志相同，只有同步素材读取视图被替换。这样可以试听较长范围是否能让同一供体形成持续摩擦声，避免把无法辨认的两个 hop 当成整个借样方向已失败。

需要保留的一项接续差异：s→a 的 22 帧对照在 1.500 秒后还有 443 个差异采样点，最大 6 LSB，差异截止约 1.5147 秒。没有为通过验收而截断这段声音或把它归零。该项仍是接缝后续排查对象；其余有借样的对照在 1.500 秒后均与各自基准逐样本相同。
