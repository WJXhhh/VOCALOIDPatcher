# 初音与天依的神经气声实测

2026 年 10 月 20 日完成 VibE-SVC2 与 BigVGAN 在初音 MIKU V4X、洛天依 V5 中文上的离线实验，结论为不采用。用户试听确认：仅声码器重建已有音色变化和明显电声感；加入技巧转换后，即使气声条件为零，音色差异也很大。该路线不满足保留原声库音色的要求，停止继续调参或声库微调。下文保留实验方法和测量供复查，声谱误差降低不代表听感通过。

## 模型与对照

转换器为 `vibe_timbre/model_200000.pt`，语义编码器为配套 HuBERT-soft，声码器为 `bigvgan_v2_24khz_100band_256x`。全部参数严格加载。独立 Python 3.11 环境使用 PyTorch `2.11.0+cu128`，在 RTX 5070 Laptop GPU 上执行。

两条输入均来自已有原生离线渲染探针，每条 176896 个采样、44.1 kHz、约 4.01 秒，包含三个 C4 音符。初音使用元音，天依包含 `l a`；它们不是完整歌词或跨音域的歌手身份测试集。实际 F0 从干净输入提取，未按目标歌手均值缩放音高。

每种声音生成 14 个响度匹配的对照，另存原始浮点结果和未修改的 44.1 kHz 输入：

1. 24 kHz 原声和仅声码器重建，用于判断基础重建损失。
2. straight 条件的完整模型重建，以及 35%、70%、100% 气声条件。中间值是学得技巧嵌入之间的实验插值，100% 为训练技巧端点。
3. 从原声 mel 加噪后开始去噪，起点为训练时间网格的 50、100、200、400/1000。每个起点均有 straight 和 breathy 对照。

技巧比较固定随机种子，不混入原声，也不使用当前白噪声 DSP。试听版按原声有声区匹配 RMS；不足一帧的模型尾部用零填充到比较长度。

现成权重只有训练歌手嵌入。实验在九个已有女声 ID 中按固定噪声的去噪损失选择参考候选，初音选到 `VocalSet#female5`，天依选到 `VocalSet#female7`；这不代表识别或克隆了原声库。

## 测量结果

下表对每帧 log-mel 功率去除整体电平，再比较有声帧平均谱形的绝对差。它描述声谱变化，不是经过听感校准的音色相似度分数，也不能转换为“保留百分比”。

| 对照 | 初音声谱差 dB | 天依声谱差 dB |
| --- | ---: | ---: |
| 仅声码器重建 | 0.57 | 0.44 |
| 完整模型 straight 重建 | 7.00 | 6.31 |
| 完整模型 breathy | 5.91 | 6.63 |
| 原声频谱起步 50，straight | 3.30 | 2.74 |
| 原声频谱起步 50，breathy | 2.95 | 3.06 |
| 原声频谱起步 100，breathy | 4.00 | 4.35 |
| 原声频谱起步 200，breathy | 4.87 | 5.55 |
| 原声频谱起步 400，breathy | 5.31 | 6.28 |

模型完整重建在技巧切换前已有较大声谱变化。降低扩散起点能使结果更接近原声，但最浅一组仍高于仅声码器重建的误差。本轮没有验证出可以直接替代现有效果器的配置。

完整 breathy 输出的中位绝对 F0 误差约为初音 8.51 音分、天依 9.75 音分；起点 50 的 breathy 为 6.20、6.93 音分。该指标针对原声有声帧，不能替代对辅音、音素边界和整句节奏的验证。

初音完整 straight→breathy 的中位 HNR 从约 23.57 降到 19.02 dB；天依同组从约 23.45 到 23.16 dB，差异较小，且都高于天依原声约 17.53 dB。不同输入与参考歌手对同一技巧条件的响应并不一致。HNR 不是气声听感或自然度的充分判据，不能据此单独判定某个输出自然。

热运行中，4 秒音频的一次完整转换与声码器约需 1.2 秒；起点 50 的浅扩散约需 0.20 秒。不含模型加载、语义特征提取和参考歌手筛选。PyTorch 统计的显存分配峰值约为 1122 MiB，不等于进程总显存。
