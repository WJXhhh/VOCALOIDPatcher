# 过渡带：工程模型、统一发布与前端接入

2026-10-18 的新菱形已改为固定 timing 范围内的独立进度控制，正式后端、保存撤销、缓存及并发验证见 [固定范围进度接入](fixed-phase-backend-integration.md)。本文下述端点拖动及后续旧起音偏移记录保留原有含义，不作为新菱形的语义。

2026-10-17。延续 [交互设计](transition-frontend-design.md) 和 [独立后端研究](standalone-transition-backend.md)。本轮修改生产源码，先完成基础链路的双版本验证，再接拖动；未部署，未启动或关闭 VOCALOID Editor。SDK 验证在独立临时进程运行，不代表真实编辑器连续鼠标操作已验收。

后续用户实测指出：过渡左端拉长只产生弱前缀，未得到音素 timing 的主体起音效果。[同音起音对照](onset-process-comparison.md)已复现并找到额外的源帧进度切口；本页的端点、归档和路由验收不能当作完整起音形态已经实现的证明。

## 控制与工程身份

`TransitionLayout.ConditionalJunctions` 根据当前整组 timing 计算相邻限制。`PreparedCoefficientTiming.QueryTransitionRange` 保留其它控制，仅替换目标共享接点，并逐个验证整数候选。返回值是实际可达集合，不能仅把最小、最大当作连续区间。缓存包含规范化 timing 与目标接点，排除 dB；已有范围的增益变化为零次原生规划。忙和超时不会计为不可达。

`Model/TransitionProjectData.cs`、`TransitionProjectArchive.cs`、`TransitionProjectBinding.cs` 和 `TransitionDocument.cs` 将临时布局与持久工程分开：

- 归档条目为 `VOCALOIDPatcher/transitions.json`，版本 1；音符使用稳定 GUID，并保留可核对的定位地址与音素拓扑。
- ART 保存左右音素身份、符号、stage、方向和重复序号。共享接点只有一个偏移秒值，同时保存完整别名集；增益按 ART 独立保存。
- 重新规划后根据中性接点加偏移，重新核对所有身份、共享关系和整组范围。不能按最近位置或相似名称换绑。
- 原生移动及撤销按音符生命周期重定位；删除后的数据留在内存供撤销，但保存时不会附着到空位置或新建的同位置音符。
- 未知版本、未知嵌套字段或未知地址语义按有界原始数据保留，打开、复制、保存不要求原生后端可用。无法执行的控制明确拒绝受控渲染。

归档限制为 4 MiB，校验重复 JSON 属性、身份、拓扑、Part 归属、数值和集合大小。工程写入接入现有原子扩展保存：扩展失败保留原 VPR 和 dirty 状态。一次手势使用一次共享 `ICustomParameterHistoryEdit`，与原生编辑、现有 timing、选样共用撤销时间线。

集成时修正了两个真实身份问题：局部规划不能读取已删除音符留给撤销的系数；复制/加载必须在 BVL 建立原生音符生命周期后绑定参数。回归覆盖同位置重建新音符、恢复旧音符以及实际 BVL 加载/复制补丁同时启用的场景。

## Part 快照只有一个发布者

`SampledTimingHost.Publish` 合并当前音符系数、音素 timing、过渡接点、ART 增益和选样契约，再发布同一个 Part/epoch 的数值快照。源工程与 UI 只改文档；生产交互不调用独立研究用的 `PublishTransitions`。

已提交路由由宿主会话持有，与 UI 临时准备的释放分离。渲染缓存身份包含所有实际数值控制；未受影响的 Part 保留原生缓存。源关闭时保留快照至原生缓存发布完成。旧 epoch、失败匹配和退休作用域不能作为成功结果接管界面。

UI 查询期间只持有捕获后的私有输入。准备在 owner/UI 线程进行，后台不访问源 SDK 或 WPF。正式发布前取消并释放匹配视图的推测查询，避免它占用同一后端导致受控渲染失败。

## 当前交互实现

Emotion 中新增“音素 / 过渡 / 选样”互斥模式。过渡带在音符行底部，原音素信息保留为上方参考，不改变音高坐标。只绘制真实 ART 范围，持续段的空白不补成假过渡。当前身份显示在工具按钮、悬停提示和精确面板。

选中段的左右端横拖调整 timing；音量横线/圆点纵拖调整 dB。按下时锁定操作类型。Shift 微调，Ctrl 单击重置，Esc、丢失捕获和切换来源取消候选。过短的段只允许选择，通过精确面板调整，避免两端命中重叠。

共享关联使用高亮和菱形标示，零几何自由度的端点显示锁定。精确面板按时间顺序列出 ART，可输入前/后覆盖毫秒及 dB，也可重置或静音。typed timing 不越过整组校验；成功后显示实际帧量化结果。

绘制层常驻，不在 MouseMove 重建视觉树。timing 查询一次只运行一个，等待项只保留最新目标；33 ms 调度合并，原生等待预算为 0，暂忙在后台有界重试。增益候选本地更新，不重新求 timing 范围。松手最终认证后一次写文档、一次历史和一次 Part 更新，拖动期间不合成音频。

手柄采用已认证坐标，光标请求另用参考线显示；范围带下方刻度标明实际可达帧。过期 revision、来源、请求结果全部丢弃。提交失败恢复源值，不把未提交候选留作真实值。

设置开关控制交互入口，保存控制的执行不依赖入口是否显示。新增 24 个翻译键，四份语言文件键集一致。布局超限、拓扑变化或版本不支持时保留数据并报告不可用，不自动删控制或输出无控制音频。

## 验证

以最低认证托管 SDK 编译，同一产物分别加载真实 6.13.1.1 / 6.13.3.1 组件。隔离入口为 harness 的 `--transition-host-probe --patcher-dse-initialization OUTPUT`，主程序集使用隔离构建，不加载模块初始化器。

实际生产保存、加载、共享/原生撤销及渲染补丁同时启用，覆盖：

- 中文 `l a` 过渡 timing、增益，组合浮点系数 .375、音素末边界及独立选样，撤销/重做逐 PCM 一致。
- 移动、变调、删除、同位置新建、恢复原音符的身份与音频；VPR 保存重开、整工程复制及扩展写失败回滚。
- 两 Part 并发与各自顺序渲染 PCM 一致；编辑第二 Part 不重新合成第一 Part；源关闭后重开命中原生受控缓存。
- 三音素 `n n#2 a` 的真实共享接点、两条 ART 独立增益、单步撤销及 VPR 重开。
- 注入未知组件/缺失模块后，timing、选样、音素音量、过渡及其组合仍可打开、复制、保存；未知控制拒绝执行。未知归档版本原始字节不变。
- 生产过渡带 WPF 离屏绘制，以及端点优先、音量线、段体、音素行隔离和短段命中规则。

托管测试 219 项、Rust 测试 44 项通过；完整解决方案 Debug/Release 使用独立 artifacts 路径构建。原生运行时使用 Release；既有 Debug 原生空规划问题未在本轮修正，不能把 Debug 编译通过当作其运行验收。

最终两版各完成 33 次真实渲染。本机当前五组组合控制的冷条件范围查询：6.13.1.1 中位 19.2 ms、最大 20.8 ms；6.13.3.1 中位 18.7 ms、最大 25.1 ms，每次约 135–140 次无音频规划，增益变化后的范围复用均为零次。它们是夹具测量，不是任意工程时限保证。重开缓存的合成作用域计数为 0、缓存键命中计数为 1。三音素本次选择的共享接点有 2 个别名、11 个可达帧，实际移动一帧后整组保存/撤销通过；不能从某一个共享端锁定推断所有共享端都锁定。

安装目录主 DLL、原生 DLL 的 SHA256 及主补丁符号链接均与修改前一致。

仍需后续真实编辑器验收连续拖动、播放中编辑、缩放滚动、快捷键及多视图交互。当前能力边界仍为完整采样 Part，最多 33 音符，捕获窗口跨度最多 22 秒，44100 Hz / 256 samples/frame / 0.5 秒 presend，不支持 AI、DVQM 或混合副声库。本轮不扩展此范围。
