# ACE Studio 四项声学参数理论备忘

保存张力 Tension、假声 Falsetto、气声 Air、力度 Energy 的声学解释、分析流程和数值映射，供后续研究使用。当前状态为资料就绪，等待下一步指令。

来源：[ACE Studio 四大声学参数底层机制解析：从 LF 声门模型到真假声的声学表征](https://www.bilibili.com/opus/1259399799840440376)，作者 Kakaru-kh，页面发布时间为 2026 年 10 月 15 日 19:54，整理日期为 2026 年 10 月 15 日。

## 四项参数概览

| --- | --- | --- | --- |
| 力度 Energy | energy / v2_energy，ch0 | 工程或合成任务传入的张量 | clamp(v / 5.2, 0, 1) |

## 张力 Tension

### 声学含义

Liljencrants–Fant 声门模型（LF）描述一个周期内的声门气流变化；Rd 是其形状控制量。原文将较小 Rd 对应于较陡的闭合和较丰富的高次谐波，较大 Rd 对应于更平缓的闭合和更强的高频衰减。这是声源模型中的描述，不能仅凭一个 Rd 值确定具体肌肉活动。

### 原文分析流程和常数

1. 使用覆盖 4 个基音周期的 Blackman 窗提取谐波，并做唇辐射补偿。
2. 与预计算 LF 频谱模板比较：64 个 Rd 格点、范围 0.02 至 3.0，每点 80 个谐波，以 200 Hz 为参考；原文记录模板能量形式为 `(S / (j + 1))²`。
3. 对 8000 Hz 以下的谐波使用 Itakura–Saito 谱散度，选择最小距离，再用抛物线插值得到连续 Rd。
4. 由 Rd 和当前基频 f0 计算 LF 理论幅度 H1 = S(f0)、H2 = S(2f0)，转换为原始张力，平滑后归一化。

原文的辐射函数和张力表达式如下。y 是与频率相关的无量纲变量，但文中未给出其完整换算定义。

```text
g(y) = y * A / sqrt(y² + A²)
A ≈ 1.441

T_raw = 20 * log10(
    (g(y1) + atan2(y1, A) + 1e-12)
    / ((H2 / (2 * H1) + 1e-30)
       * (g(y2) + atan2(y2, A) + 1e-12))
)

原文在 f0 ≈ 200 Hz 附近给出的近似：
T_raw ≈ -6.015 - 20 * log10(H2 / (2 * H1))
```

原文采用的带符号幂变换可统一记为：

```text
B(v; λ+, λ-, N) = sign(v) * ((abs(v) + 1)^λ - 1) / (λ * N)
λ = λ+ when v >= 0, otherwise λ-

B_T = B(GaussianSmooth(T_raw); 0.7119, 1.2881, 4.0847)
Tension = clamp((B_T + 2.2) / 5.0, 0, 1)
```

文中没有给出高斯核宽度、边界处理及完整谐波幅度归一化约定。

### 原文对 ACE 和 Synthesizer V 的管线解释

作者认为，两者都使用与 LF/Rd 有关的标尺，但 ACE 将修改后的张力作为声学模型条件，Synthesizer V 则在合成末端直接调整 Rd。文中给出的 SV 映射为：

```text
t ∈ [-1, 1]
t > 0: Rd_out = Rd - 0.5 * t * (Rd - 0.1)
t <= 0: Rd_out = Rd + 0.8 * abs(t) * (3.0 - Rd)
```

这些是原文对特定实现的判断；文章未提供可在此核对的软件版本、源码位置或复现实验包。

## 假声 Falsetto

### 原文提取定义

假声分析复用张力分析得到的 Rd，不再单独估计一个声源维度：

```text
F_raw = -log2(Rd)
B_F = B(GaussianSmooth(F_raw); 0.742, 1.258, 0.8039)
Falsetto = clamp((B_F + 2.3) / 6.6, 0, 1)
```

因此原文所述两个 baseline 具有共同的潜变量。作者报告在 920 个稳定段有效采样点上，二者相关系数为 -0.9995；这一数值适用于该实验，不能据此断言两个合成控制量始终可互换。

### 区分声区与张力的另一种思路

原文援引 Keating 2014 年的《Acoustic Measures of Falsetto Voice》，讨论控制基频后，H1*−H2* 对假声识别的局限，以及 H2*−H4* 的作用。星号表示经过共振峰影响修正的谐波测量。

文章还记录了一个 DiffSinger 实验分支的候选指标：

```text
Falsetto_DS = E_H2 / (E_H2 + E_H4 + 1e-5)
```

E 表示谐波能量。当 E_H4 相对减小时，该值升高。原始谐波能量仍受元音共振峰影响，不能直接等同于修正后的 H2*−H4*，也不能作为无条件的生理声区分类器。文章提到 PR #239，但没有提供仓库地址，后续核验应先确定项目与版本。

## 气声 Air

### 声学含义与原文流程

气声可包含声门漏气产生的非周期噪声。文章以部分频带内的谐波与噪声比例作为分析量，而非直接测量全频带噪声。

```text
F = fs / 2
band[i] = 228.8 * ((1 + F / 228.8)^(i / 24) - 1)

m_b = 10 * log10(E_harmonic,b / E_noise,b)
m = (m_12 + m_13 + m_14 + m_15 + m_16) / 5
Air_raw = 1 / (1 + 10^(m / 10))
Air = clamp(GaussianSmooth(Air_raw), 0, 1)
```

原文描述 24 个近似 ERB 刻度频带，只使用索引 12 至 16 的 5 带。该指标在谐波和噪声同时乘以相同增益时保持不变。频带选择、谐噪分离方法、静音处理和极小能量保护会影响实际结果。

### 按公式计算得到的两点区别

原文称所用范围约为 2.3 至 5.1 kHz。按上式代入 fs = 44100 Hz，若 band[i] 是零基频带下界，第 12 至 16 带的并集实际为约 2028.94 至 5631.66 Hz；应回查原始索引和边界约定。

原文把最终值解释为合并频带的噪声功率占比。但先平均 dB 得到的是线性谐噪比的几何平均：

```text
r_b = E_harmonic,b / E_noise,b
10^(mean(m_b) / 10) = (r_12 * r_13 * r_14 * r_15 * r_16)^(1/5)
```

因此该公式是基于几何平均谐噪比的指标，通常不等于 `sum(E_noise) / sum(E_noise + E_harmonic)`。以上两点为整理时的公式核算。

## 力度 Energy

### 原文数据来源与映射

作者认为，Energy 的 baseline 来自工程中的 energy / v2_energy 或合成任务数据，本地参数分析器读取并插值该张量；另一条 128 带 log-mel 特征链不参与此处 Energy 的生成。

```text
v_safe = clamp(v_input, -1, 1)
v = InterpolateToTargetGrid(v_safe)
Energy = clamp(v / 5.2, 0, 1)
```

原文把低面板值归因于固定除数 5.2，并报告样本中原始值约 0.0001 至 0.4950、显示值最高约 0.0952、均值约 0.0095。这些是样本统计，不是所有歌声的必然范围。

### 原文经验拟合

```text
v ≈ (sum_b sqrt(P_b))^0.7
```

作者报告此经验量与音频包络的相关性约 0.9955。文中未给出滤波器组、幅度尺度等复现条件；该式应保留为拟合假设，不能替代实际张量生产逻辑。

若严格按文中先限制到 [-1, 1] 再除以 5.2 的流程，且插值无过冲，Energy 上限仅约 0.1923。因此原文将 5.2 解释为面板绝对满量程的说法，还需要结合实际数据流核验。

## 后续研究需要补齐的定义

- 张力表达式把 g(y) 幅度项与 atan2 相位项直接相加，其物理解释需要核对；还需确定 S 表示气流谱还是气流导数谱，避免重复处理频率因子。
- 四项曲线的时间步长、无声与清音帧规则、高斯核参数，以及内部值与用户控制值的换算仍需原始实现或受控实验。
- 唇辐射补偿不等于去除声道共振峰；不能由此推出 Rd 拟合不受元音影响。
