# ACE 参数本地声学后端

四条参数曲线保留原生 ParameterView 的编辑、历史和工程归档，但发声改为处理渲染后的 PCM。提交曲线不再生成 Dynamics、Breathiness、Air、Brightness 或 Character 控制点。此实现提供独立的声学处理，不复刻 ACE Studio 的云端模型。

2026 年 10 月 20 日试听反馈：正向气声存在明显的叠加白噪声感。下述气声运算是当前实验实现，尚未通过自然度验收；能量和残差测试通过不能替代听感。新的合成机制、权重可用性与接入限制见 [2026 气声合成资料与接入评估](ace-air-recent-research.md)。

## 参数与声学运算

面板继续使用 0..100、中性值 50。处理量 `u = (value - 50) / 50`，范围为 -1..1。这是相对原声的调整量，不是文章中的自动 baseline 标尺。四条曲线均为 50 时，WAVE 文件和 PCM 均保持逐字节一致。

| 参数 | 本地运算 | 验收重点 |
| --- | --- | --- |
| 力度 | 逐采样幅度增益 `10^(18u/20)`，范围 -18 至 +18 dB | 独立增益，不改写 Dynamics |
| 气声 | 正向按整帧有声能量生成声谱包络塑形的气流噪声；负向在 ERB 第 12..16 带衰减非谐波分量 | 暗音色也能增加气声；清音和静音保留 |
| 张力 | 估计基频和近似声源 Rd，以目标与原始 LF 频谱之比调整有声谐波 | 较紧声源保留更多高次谐波；不转调 |
| 假声 | 对声源中 H2 以上谐波施加相对谐波序号的衰减或增强，正向每倍频程最多衰减 12 dB | H2/H4 改变，基频保持；不是 Character 或声库切换 |

假声是声学上的近似变换，不能从任意真声录音恢复另一套真实假声采样、声区或歌手模型。自动 baseline 分析显示、ACE 训练条件及神经声码器均不在本次实现内。

## LF 声源模型

`LfGlottalModel` 独立实现周期归一化的 LF 气流导数模型：开放段为指数乘正弦，回归段为指数衰减。以 Rd 推导时序，再数值求解回归时间常数与开放段系数，满足闭合处连续及全周期积分为零。

频谱直接由两段函数的解析积分得到，不对低采样率声门脉冲做 FFT。相关理论见 [Gobl 2021 的 LF 频域模型](https://www.isca-archive.org/interspeech_2021/gobl21_interspeech.pdf)。Rd 到时序的经验参数化有适用范围，不能把它看作所有声型的精确生理模型；[Gobl 2017](https://www.isca-archive.org/interspeech_2017/gobl17_interspeech.html) 讨论了这一类约束。

实现使用 48 个 Rd 模板，模型范围 0.5..2.7，最多 128 阶谐波。基频通过归一化自相关估计，搜索约 65..1200 Hz；低置信度帧不做声源修改。预加重 LPC 用于近似抵消声道包络，然后以谐波对数幅度进行模板匹配。

声源与声道的分离存在歧义，特别是高音、共振峰靠近基频或不规则发声。估计值保留在 0.75..2.45，留出双向调节余量，避免 LPC 吸收声源倾斜后把一个方向的旋钮钉死在模型端点。该估计不是对歌手真实 Rd 的精确测量。

张力的目标 Rd 按方向向模型上下限移动，最大移动剩余距离的 80%。合成使用 LF 目标/原始幅度比，保持输入相位与原有声道共振结构；不宣称重建了完整声门相位或生理闭合过程。

## 音频处理与边界

- 2048 点 Hann 窗，512 点步长，频域处理后将差值重叠相加到原始 PCM。
- 谐波掩码依赖当前基频，不是固定频率的高低音旋钮。源谱增益有界，避免放大接近零的谐波。
- 源形态和谐噪调整后进行帧能量归一化，再独立应用力度增益。
- 所有源形态曲线回到中性的位置，采样域差值也归零，避免 STFT 窗口把效果带进后续音符。
- 降低气声时按实际采样率计算 ERB 边界。44.1 kHz 时索引 12..16 对应约 2029..5632 Hz。
- 增加气声时使用整帧有声能量预算，满幅最多分配 40% 帧功率，曲线为 `0.4 * u^1.3 * voicedConfidence`。噪声按跨谐波平滑的声谱包络塑形，并使用宽带底限、500 Hz 高通形状与 8 kHz 低通形状，避免暗音色的高频缺失限制气声强度。这些是本地合成参数，不是 ACE 分析器公式。
- 噪声按绝对采样位置生成，同一采样在重叠窗内保持一致；重复处理确定性不变，也避免逐帧独立随机相位在重建中互相抵消。

WAVE 读取支持单声道和双声道、16/24/32 位整数 PCM、32 位浮点及对应 extensible 子格式。独立分析路径可输出 32 位浮点；宿主路径输出 PCM16，因为 VOCALOID 的托管 WaveFile 读取器只接受 44.1 kHz PCM16。宿主写出在幅度 0.9 以上采用连续软拐点限幅，防止力度增益超过整数余量时硬削波。

文件长度、数据块边界、采样布局、数值有限性均有检查。单文件上限 128 MiB，解码样本总数上限 1600 万；超限时不处理，预览回退原声，导出明确提示失败。最直接的频率覆盖验证为 16、44.1、48 kHz，当前 VOCALOID 渲染使用 44.1 kHz。

## 宿主生命周期

`AceParameterMappingService` 保留原有类名作为归档和生命周期桥接，不再向发声控制器写入派生曲线。载体仍为经验证的 WeightHmm、S5Air、XSynth、Expression；归档版本和格式不变。

提交、Undo/Redo、打开工程、设置变更后在 Dispatcher 捕获不可变曲线。按 tempo 变化点切分 tick 插值，再转换到 Part 音频的秒坐标，包含 PresendTime。后台不读取 VSM 对象。

`AceAcousticHost` 在 120 ms 稳定期后处理，使用取消令牌和 generation 丢弃过时结果，全局只允许一个音频处理工作进入重计算。开始渲染时失效同路径缓存；完成渲染后读取新音频。文件短暂占用有有限次数重试。失败时保留原声，日志只记录异常类型。

文件替换顺序为 BVL → 单音素音量 → 过渡平滑 → ACE。ACE 的输入读取只绕过自己，避免重复处理；当上游生成新的派生文件时重新绑定。发布结果后更新播放 placement 和钢琴窗波形。关闭工程时取消任务，清理自建缓存文件。

导出准备入口改为各派生音频功能共用，先等待上游，再同步完成 ACE 文件处理。非中性曲线尚未得到可用原始渲染或处理失败时阻止导出，避免静默导出未经处理的音频。

设置项沿用 `AceParameterMapping` 和 `AceFalsettoMapping` 存储键，界面含义分别改为声学处理与假声声源处理；旧 `AceAirUseNativeAir` 值仅为配置兼容保留，不再参与发声。

旧映射版已保存的 Dynamics 等原生曲线仍属于工程数据。本版不自动删除它们，因为旧版本没有保留可恢复的原始曲线；验证独立 DSP 时应使用新工程或已知的原生参数基线。
